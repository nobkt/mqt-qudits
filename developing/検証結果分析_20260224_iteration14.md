## 1. 問題の概要

### 1.1 ノイズ影響の過大さ

iteration 12の検証結果によると、ノイズ有りシミュレーションの精度が極端に悪い:

- **Qudit DM vs Qudit noisy: F = 0.0897** (10ステップ、p_depol=0.01, p_dephasing=0.005)
- **Qubit DM vs Qubit noisy (norm): F = 0.1142** (同条件)

これは1ステップあたり76回のノイズ適用（12回ペア脱分極 + 20回単一サイト脱分極 + 44回位相緩和）が原因。
10ステップで累計760回のノイズが適用され、量子状態がほぼ最大混合状態に収束する。

### 1.2 ノイズ適用箇所の分析

現行実装では、ノイズは以下の全てのゲート操作後に適用されている:

| フェーズ | 操作 | 脱分極 | 位相緩和 |
|---------|------|--------|---------|
| Hamiltonian前半 | 3ペア転送ゲート | 3回(pair) | 6回(single) |
| Lindblad (TTA pair) | 6チャネル | 6回(pair) | 12回(single) |
| Lindblad (single-site) | 20チャネル | 20回(single) | 20回(single) |
| Hamiltonian後半 | 3ペア転送ゲート | 3回(pair) | 6回(single) |
| **合計** | | **32回** | **44回** |

**問題点**: 単一サイトLindbladチャネル（蛍光、リン光、IC、ISC）は物理的に
1分子ローカルな操作であり、実デバイス上では単一qudit/qubitゲートで実装される。
単一qubit/quditゲートの誤差率は2-qubit/quditゲートと比較して桁違いに小さい
（典型的に10^-4 vs 10^-2）。全てのゲートに同じ脱分極確率を適用するのは
物理的に過剰なノイズモデルである。

### 1.3 解決アプローチ

脱分極ノイズを**2-qubit/2-qudit以上の相互作用のみ**に限定することで:

1. 物理的により現実的なノイズモデルとなる
2. ノイズ適用回数が76回→12回/ステップに削減（62.5%削減）
3. qubit表現とqudit表現の**公平な比較**が可能になる

## 2. 実施した修正

### 2.1 `depol_pair_only` パラメータの追加

4つの全ノイジーシミュレータに `depol_pair_only: bool = False` パラメータを追加:

1. **`QuditGKSLNoisySimulator`** (qudit_gksl_noisy_simulator.py) — 密度行列版
2. **`QubitGKSLNoisySimulator`** (qubit_gksl_noisy_simulator.py) — 密度行列版
3. **`QuditGKSLNoisyShotSimulator`** (qudit_gksl_shot_simulator.py) — ショットベース版
4. **`QubitGKSLNoisyShotSimulator`** (qubit_gksl_shot_simulator.py) — ショットベース版

### 2.2 動作仕様

- `depol_pair_only=False` (デフォルト): 既存の動作と完全に同一。全ゲート後にノイズ適用。
- `depol_pair_only=True`: 単一サイトLindbladチャネル後のノイズ適用をスキップ。

ペアのみモードでのノイズ適用箇所:

| フェーズ | 操作 | 脱分極 |
|---------|------|--------|
| Hamiltonian前半 | 3ペア転送ゲート | 3回(pair) |
| Lindblad (TTA pair) | 6チャネル | 6回(pair) |
| Lindblad (single-site) | 20チャネル | **0回** (スキップ) |
| Hamiltonian後半 | 3ペア転送ゲート | 3回(pair) |
| **合計** | | **12回** |

### 2.3 後方互換性

デフォルト値 `depol_pair_only=False` により、既存のコードは一切影響を受けない。
ノートブック `quantum_dynamics_gksl_comparison.ipynb` で使用されている

## 3. ペアのみノイズでの Qubit vs Qudit 比較の理論的根拠

### 3.1 脱分極チャネルの数学的差異

**Qudit (d=3)** ペア脱分極:
- チャネル: E(ρ) = (1-p)ρ + (p/d²)I⊗Tr(ρ), d²=9
- Weyl-Heisenberg演算子: d⁴-1 = 80個の非恒等演算子
- 非恒等確率: p·(1 - 1/d⁴) = p·(1 - 1/81) ≈ 0.988p
- **forbidden stateなし**: qutrit空間で閉じている

**Qubit (d=4)** ペア脱分極:
- チャネル: E(ρ) = (1-p)ρ + (p/d²)I⊗Tr(ρ), d²=16
- Pauli演算子: d⁴-1 = 255個の非恒等演算子
- 非恒等確率: p·(1 - 1/d⁴) = p·(1 - 1/256) ≈ 0.996p
- **forbidden state leakage**: 各分子の2-qubit Pauliのうち12/15 (80%)がleakageを起こす

### 3.2 期待される結果

ペアのみノイズモードでは:
- Quditの方が各ペア脱分極でのエラー確率がわずかに低い（0.988p vs 0.996p）
- Qubitはforbidden state leakageにより qutrit部分空間のトレースが減少
- この2つの効果により、**Qudit表現がQubit表現よりノイズ耐性が高い**ことが
  定量的に示されるはずである
