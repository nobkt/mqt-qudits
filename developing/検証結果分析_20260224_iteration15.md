## 2. 発見された問題点

### 問題1（重要）: Trotter収束性の未検証

**深刻度**: 高

**内容**: 全シミュレーションで dt = t_max / n_steps = 10.0 / 10 = 1.0 を使用している。
Stinespring + 2次Trotter分解の近似誤差は O(dt²) であり、dt=1.0 ではこの誤差が
無視できない可能性がある。

**具体的影響**:

1. **Stinespring近似誤差**: 各Lindbladチャネルに対するStinespringチャネルは
   正確には E(ρ) = ρ + dt·D(ρ) + O(dt²) であり、GKSL散逸子の厳密な1ステップ
   進化 e^{D·dt}(ρ) とはO(dt²)の差がある。dt=1.0では、最大のLindblad演算子
   (gamma_TTA=0.05, ||L||≈0.224) に対して θ·||L|| ≈ 0.224 であり、
   sin²(0.224) ≈ 0.050 vs 正確な値 dt·gamma/2 = 0.025 と約2倍の差がある。

2. **Trotter分割誤差**: 26個のLindbladチャネルを個別に適用する際の非可換性誤差
   O(dt² · Σ_{k<l} [D_k, D_l]) が蓄積する。

3. **問題の本質**: ノイズレスの参照結果自体にTrotter誤差が含まれており、
   ノイズ有り結果との忠実度比較がTrotter誤差を含んでいる可能性がある。
   ただし、同じTrotter分解を使用しているため、ノイズレス vs ノイジーの
   比較ではTrotter誤差が部分的に相殺される。

**検証方法**: n_steps を変えた（dt を小さくした）収束テストが必要。
さらに、qudit空間（dim=81）ではGKSL Liouvillian超演算子の行列指数関数
exp(L·t) による厳密解との比較が可能（81²=6561 次元）。

### 問題2（重要）: DM ノイジー vs ショットノイジーの整合性未検証

**深刻度**: 高

**内容**: Iteration 14の検証では、DM ノイジーは1ステップのみ（Test 1）、
ショットベースは10ステップ（Test 2）で実行されている。しかし、**同じ条件
（10ステップ、pair-only）での DM ノイジーとショットノイジーの直接比較が
行われていない**。

**なぜ重要か**:

- DM ノイジーシミュレータ（`QuditGKSLNoisySimulator`, `QubitGKSLNoisySimulator`）は
  iteration 13 で致命的バグ（メソッドシグネチャ不一致、未定義メソッド呼び出し）が
  発見され、修正された
- ショットベースシミュレータは以前から正常動作していた
- 修正後の DM ノイジーの正確性を、ショットベースと比較して検証すべき

**期待される結果**: DM ノイジーとショットベース（n_shots→∞）は数学的に等価。
n_shots=1000 でも、統計誤差 ~1/√1000 ≈ 0.03 の範囲で忠実度が一致するはず。

### 問題3（中程度）: F_norm メトリクスの誤解を招く性質

**深刻度**: 中

**内容**: Qubit結果の F_norm（トレース正規化後の忠実度）は、ノイズ耐性の
公平な比較指標ではない。

**具体的数値**:

- Qudit pair-only F = 0.3771
- Qubit pair-only F_raw = 0.3315
- Qubit pair-only F_norm = 0.5238

F_norm > F(qudit) だが、これは Qubit が Qudit より優れていることを意味しない。

**理由**: F_norm はトレース正規化により forbidden state への leakage を無視する。
Qubit ノイズの一部は population を forbidden state に移動させ、物理部分空間内の
scrambling を減らす。その結果、物理部分空間内の状態は（正規化すると）
見かけ上忠実度が高くなる。

**公平な比較指標**:

1. **F_raw**: leakage を含む生の忠実度（Qudit=0.377 > Qubit=0.332 で Qudit 優位）
2. **有効忠実度**: F_eff = F_raw / Tr(ρ_noisy) — 物理部分空間に残った割合を考慮
3. **Leakage率の明示的報告**: Qubit の forbidden state population を各ステップで追跡

### 問題4（中程度）: ショットベース結果に含まれる統計ノイズの未分離

**深刻度**: 中

**内容**: Test 2のショットベース結果（n_shots=1000）には、ハードウェアノイズの
効果と量子トラジェクトリー法の統計ノイズが混在している。
これらを分離していないため、観測された忠実度低下のうちどれだけが
ハードウェアノイズによるものかが不明確。

**解決方法**:

1. DM ノイジーで同じ条件の10ステップを実行（統計ノイズなし）
2. ノイズレスのショットベースで10ステップを実行（統計ノイズのみ）
3. 三者を比較することで各効果を分離

### 問題5（軽微）: forbidden state population の未追跡

**深刻度**: 低

**内容**: ショットベースの Qubit 結果で trace（qutrit部分空間のトレース）は
追跡されているが、明示的な forbidden state population は報告されていない。
DM ノイジーの Qubit 結果でも forbidden state population は Test 1（1ステップ）
でのみ報告されている。

**影響**: leakage のメカニズム（どの forbidden state にどれだけ leakage するか）
の詳細分析ができない。

### 3.2 設計上の注意点

**Stinespringチャネルの性質**: Stinespring dilation による散逸チャネルは、
GKSL散逸子の線形近似 (ρ + dt·D(ρ)) ではなく、正確な量子チャネル
（完全正値トレース保存写像）である。ただし、GKSLマスター方程式の
厳密な解 exp(L·dt)(ρ) とは O(dt²) の差がある。この差は dt→0 の極限で
消失する。

**ノイズ配置の整合性**: DM ノイジーとショットベースノイジーのノイズ配置は
完全に一致している（iteration 13 の修正により整合）:

```
Half Hamiltonian → NN pair depol (+ dephasing)
├── Lindblad channel 1 (TTA pair) → pair depol (+ dephasing)
├── ...
├── Lindblad channel 6 (TTA pair) → pair depol (+ dephasing)
├── Lindblad channel 7 (single-site) → [pair-only: skip] / depol + dephasing
├── ...
└── Lindblad channel 26 (single-site) → [pair-only: skip] / depol + dephasing
Half Hamiltonian → NN pair depol (+ dephasing)
```

## 5. 結論

Iteration 14 のコード修正（depol_pair_only パラメータ追加）は正確に実装されており、
コードにバグは検出されなかった。しかし、検証結果の解釈には以下の注意が必要:

1. **Trotter近似誤差の定量化がされていない** — dt=1.0 での結果の精度が不明
2. **DM ノイジーの多ステップ検証が不足** — iteration 13 で修正されたコードの
   信頼性確認が不十分
3. **比較メトリクスの改善が必要** — F_norm は leakage を隠蔽するため、
   F_raw とleakage率の併記が望ましい

これらの問題はコードのバグではなく、検証方法の不足であるため、
iteration 15 の検証スクリプトで対処する。
