## 2. 発見された問題

### 問題1（重大）: Stinespring近似誤差が未検証

**現状**: Test A の「Trotter収束性」テストは、Stinespring+Trotter法の異なるdt値での結果を n_steps=100 の Stinespring+Trotter 参照解と比較している。

**問題点**: 参照解自体もStinespring近似を使用しているため、Stinespring近似誤差が相殺され、測定されるのはTrotter分割誤差のみである。

**根拠（数値的証拠）**:

Test A のTrotter不忠実度の dt 依存性:

| n_steps | dt   | Trotter不忠実度 | 比率 (前段との) |
|---------|------|----------------|----------------|
| 5       | 2.0  | 1.40×10⁻⁴     | —              |
| 10      | 1.0  | 3.18×10⁻⁵     | 4.4×           |
| 20      | 0.5  | 6.26×10⁻⁶     | 5.1×           |
| 50      | 0.2  | 2.50×10⁻⁷     | 25.0×          |

dt を 2 倍小さくすると不忠実度が約 4〜5 倍減少 → O(dt²) 収束。これは2次Trotter分割の理論収束次数と一致する。

**しかし、これはStinespring近似の正確さを証明しない。**

Stinespring dilation の数学的性質:

```
U_stine = expm(-i * sqrt(dt) * G)
E_α(ρ, dt) = Tr_env[U (|0><0| ⊗ ρ) U†]
```

展開すると:
```
E_α(ρ, dt) = ρ + dt * D_α[ρ] + c₂ dt² + O(dt^{5/2})
```

ここで `D_α[ρ] = L_α ρ L_α† - ½{L_α†L_α, ρ}` は正しいGKSL散逸子。

一方、正確な散逸子の指数関数は:
```
exp(D_α dt)[ρ] = ρ + dt * D_α[ρ] + dt²/2 * D_α²[ρ] + O(dt³)
```

O(dt²) 項が異なるため、Stinespring写像は各ステップで O(dt²) の誤差を持つ。T/dt ステップの累積で O(dt) の誤差となる。

**結論**: Trotter分割誤差は O(dt²) で収束するが、Stinespring近似誤差は O(dt) でしか収束しない可能性がある。現在の検証ではこの寄与を分離できていない。

**修正方針**: 正確な GKSL Liouvillian の解（`ClassicalGKSLSimulator` が既に実装済み）との比較テスト（Test E）を追加する。これにより:
- Stinespring+Trotter法の**真の全体誤差**を測定
- **Stinespring近似誤差**と**Trotter分割誤差**を分離
- 実用的な dt 値での精度を定量化

### 問題2（軽微）: Test C の dt依存性報告が不正確

**現状**: Markdown レポートテンプレートに以下が**ハードコード**されている:

```
**ε の dt 依存性は ~0.1% 以下。ノイズは本質的にゲートノイズ。**
```

**実際のデータ**:

| dt   | ε          |
|------|------------|
| 0.20 | 0.10097393 |
| 0.50 | 0.10072589 |
| 1.00 | 0.10044439 |
| 2.00 | 0.10008015 |

- 絶対差: max - min = 0.00089378
- 相対変動: 0.00089378 / 0.10055 ≈ **0.89%**

「~0.1% 以下」はε の絶対値の0.089%ポイントという意味では誤りではないが、相対変動としては ~0.9% であり、ミスリーディングである。

**修正方針**: dt 変動量を実データから計算して出力するように修正し、ハードコード文を削除する。

### 問題3（中程度）: 密度行列の妥当性検証が不足

**現状**: 検証スクリプトはステップごとの fidelity と population を追跡しているが、密度行列自体の物理的妥当性（トレース保存、エルミート性、正値性）を検証していない。

**問題点**: `gksl_validation.py` に `validate_density_matrix` 関数が既に存在するにもかかわらず、検証スクリプトで使用されていない。Stinespring近似やノイズチャネルの適用過程で数値的な問題が発生していないことを確認する必要がある。

**修正方針**: Test E にて密度行列診断（トレース、エルミート性ノルム、最小固有値）をステップごとに記録する。
