## 2. 発見された問題

### 問題1（重大）: quantum_fidelity() の数値精度喪失

**現状**: `quantum_fidelity()` 関数の `min(..., 1.0)` クリッピングにより、古典 Trotter (CT) vs Exact の忠実度が n_steps≥20 で正確に 1.0 に丸められ、不忠実度が 0.0 になっている。

**数値的証拠**:

| n_steps | dt | F_CT_vs_exact | infid_CT_vs_exact | T_CT_vs_exact |
|---------|-----|--------------|-------------------|---------------|
| 5 | 2.00 | 0.9999937859 | 6.214e-06 | 1.239e-03 |
| 10 | 1.00 | 0.9999997775 | 2.225e-07 | 3.070e-04 |
| 20 | 0.50 | **1.0** | **0.0** | 7.658e-05 |
| 50 | 0.20 | **1.0** | **0.0** | 1.224e-05 |

n_steps=20 で T_CT_vs_exact = 7.658e-05 > 0 なのに infid_CT_vs_exact = 0.0 となっている。これは ρ_CT ≠ ρ_exact であることとの矛盾であり、忠実度計算の数値精度が不十分であることを示す。

**原因**:

```python
def quantum_fidelity(rho, sigma):
    ...
    return float(min(np.real(np.sum(np.sqrt(evals_m))) ** 2, 1.0))
```

81×81 密度行列のチェーン演算（固有分解 → 平方根 → 行列積 → 固有分解 → 平方根の合算 → 二乗）の累積数値誤差が、真の不忠実度（~10⁻⁸〜10⁻⁹ と推定）を上回り、計算された F が 1.0 を僅かに超過するため `min(..., 1.0)` で 1.0 にクリップされる。

n_steps=10 の infid = 2.225e-07 と Rate(1-F) ≈ 4.8 から外挿すると:
- n_steps=20 の真の infid ≈ 2.225e-07 / 2^{4.8} ≈ 8.0e-09
- n_steps=50 の真の infid ≈ さらに小さい

これらは 81×81 行列の忠実度計算の精度限界（~10⁻¹⁰ 程度）に近い。

**影響**: CT vs Exact の忠実度ベース収束次数が NaN になる（3つの区間のうち2つが計算不能）。

**修正方針**: 以下の2段階アプローチ:
1. 不忠実度が精度限界以下の場合を検出するフラグを追加
2. 忠実度ベースの解析が信頼できない場合、トレース距離ベースの解析を主要メトリクスとして使用

### 問題2（重大）: (1-F)/T² ≈ 1 の期待が混合状態に対して不正確

**現状**: Iteration 19 のスクリプトは `ratio_1mF_over_T2 = infid / T²` を計算し、これが約 1.0 になることを期待している（「1-F ≈ T² 関係の検証」と記載）。

**数値的証拠**: (1-F)/T² 比は 1.0 とは程遠い:

#### 収束データ（ST vs Exact）

| n_steps | dt | (1-F)/T² |
|---------|-----|---------|
| 5 | 2.00 | 29.56 |
| 10 | 1.00 | 44.57 |
| 20 | 0.50 | 52.57 |
| 50 | 0.20 | 47.93 |

#### ステップごとのデータ（n_steps=10）

| Step | (1-F)/T² |
|------|---------|
| 1 | 106.93 |
| 2 | 127.18 |
| 3 | 155.29 |
| 4 | 171.73 |
| 5 | 179.16 |
| 6 | 159.86 |
| 7 | 124.30 |
| 8 | 89.32 |
| 9 | 62.91 |
| 10 | 44.57 |

**原因**: `1-F = T²` が成立するのは **純粋状態のみ** である。

Fuchs–van de Graaf 不等式:
```
T² ≤ 1-F ≤ 2T - T²
```

- 純粋状態 |ψ⟩⟨ψ| と ρ の忠実度: F = ⟨ψ|ρ|ψ⟩
  - トレース距離: T = √(1 - F)
  - よって: 1-F = T² (等号成立)
  
- **混合状態** ρ と σ の忠実度: F = (Tr√(√ρ σ √ρ))²
  - T² ≤ 1-F は常に成立
  - しかし (1-F)/T² は 1 以上の任意の値をとりうる
  - 混合度が高いほど (1-F)/T² は大きくなる傾向がある

本シミュレーションでは、ρ_exact および ρ_ST はいずれも散逸による混合状態であるため、(1-F)/T² >> 1 は正常な挙動である。

**ステップごとの比の変動の説明**:

ステップごとの (1-F)/T² 比は 45〜179 の範囲で変動する。これは ρ_exact の純度（purity）がステップごとに変化するためである:
- Step 0: 純粋状態（purity = 1.0）→ (1-F)/T² = 1（理論値）
- Step 1〜5: 散逸進行中、純度が急速に低下 → 比が増加
- Step 6〜10: 散逸がさらに進行 → 比が減少に転じる

比の変動パターンは、系の散逸ダイナミクスの特性を反映しており、問題ではなく物理的情報を含む。

**重要**: 比が 1 でないことは **計算誤差ではない**。Fuchs-van de Graaf 不等式の上界 T² ≤ 1-F が混合状態で等号にならないことの正しい反映である。

**修正方針**:
1. `(1-F)/T² ≈ 1` の期待を削除
2. 代わりに Bures 距離 d_B = √(2(1-√F)) を追加し、d_B と T の比を追跡
3. 各状態の純度（purity）を追加し、(1-F)/T² 比の変動を説明可能にする

## 4. 理論的まとめ

### Stinespring 近似の誤差構造

Stinespring ユニタリ U = exp(-i√dt G) による量子チャネル:

```
E(ρ) = Tr_E[U(|0⟩⟨0| ⊗ ρ)U†]
     = ρ + dt·D[ρ] + dt²·c₄(ρ) + O(dt³)
```

正確な散逸子チャネル:
```
exp(D·dt)[ρ] = ρ + dt·D[ρ] + (dt²/2)·D²[ρ] + O(dt³)
```

- ステップあたり誤差: O(dt²)（密度行列のノルム差）
- 累積誤差（T/dt ステップ）: O(dt)（トレース距離）
- **忠実度不忠実度**: O(dt²)（∵ 1-F ∝ T² の比例関係）

### 忠実度とトレース距離の関係（混合状態）

Fuchs-van de Graaf 不等式:
```
T² ≤ 1-F ≤ 2T - T²
```

- **純粋状態**: T² = 1-F（等号成立）
- **混合状態**: T² < 1-F（一般に厳密な不等号）
- **比例関係**: Rate(1-F) ≈ 2 × Rate(T) は混合状態でも成立
  - これは 1-F ∝ T² が（非単位）定数 C(ρ) とともに成立することを意味
  - C(ρ) は参照状態 ρ の混合度に依存

### Bures 距離の位置づけ

Bures 距離 d_B = √(2(1-√F)):
- d_B ≈ √(1-F)（小さい不忠実度で）
- T ≤ d_B（Fuchs-van de Graaf から導出）
- d_B は三角不等式を満たす距離メトリクス
- 混合状態では d_B >> T となりうる
