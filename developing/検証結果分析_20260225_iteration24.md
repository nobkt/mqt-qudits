## 改善点1（軽微）：正規化係数の系統的ドリフトと平均値ベースフィッティングの限界

### 症状

正規化誤差係数 T/dt^n は dt が大きいほど真の漸近値からずれる：

| dt | T(ST,SCPT)/dt | T(SCPT,ex)/dt² | T(CT,ex)/dt² | T(SCPT,CT)/dt² |
|----|-------------|---------------|-------------|---------------|
| 2.00 | 1.980144e-04 | **3.104642e-04** | **3.096975e-04** | 1.024229e-06 |
| 1.00 | 1.986149e-04 | 3.077508e-04 | 3.069715e-04 | 1.036699e-06 |
| 0.50 | 1.986044e-04 | 3.070837e-04 | 3.063013e-04 | 1.039785e-06 |
| 0.20 | 1.985017e-04 | **3.068977e-04** | **3.061144e-04** | 1.040647e-06 |

T(SCPT,ex)/dt² は dt=2.0 で 3.105e-04、dt=0.2 で 3.069e-04。ドリフト幅は 1.2%。

### 原因

真のスケーリングは T = c₀·dt^n + c₁·dt^(n+1) + c₂·dt^(n+2) + ... であり、T/dt^n = c₀ + c₁·dt + c₂·dt² + ... は dt→0 でのみ c₀ に収束する。大きい dt のデータが含まれると、平均値 mean(T/dt^n) は c₀ よりも系統的に大きくなる。

### 数値的影響

| 成分 | mean(T/dt^n) | R₀(dt=0.2) | 差 | 相対差 |
|------|-------------|-----------|-----|-------|
| Stinespring | 1.984338e-04 | 1.985017e-04 | -6.79e-08 | 0.034% |
| Strang | 3.080491e-04 | 3.068977e-04 | 1.15e-06 | 0.37% |
| 回文順残差 | 1.035340e-06 | 1.040647e-06 | -5.31e-09 | 0.51% |

Stinespring 成分はドリフトが非常に小さい（0.034%）ため影響は無視可能。Strang 成分で 0.37% の系統バイアスがある。

### 推奨修正

1. **高次フィッティング**の追加: T = c₀·dt^n + c₁·dt^(n+1) で c₀ を推定（線形回帰 T/dt^n = c₀ + c₁·dt）
2. **Richardson 外挿**の追加: 最小2つの dt 値から dt→0 外挿値を計算
3. 両方の推定値を平均値と共に出力し、一致を確認

## 改善点2（軽微）：誤差ベクトルの幾何学的解析の欠如

### 症状

相殺比 cancel_SCPT = T(ST,ex) / (T(ST,SCPT) + T(SCPT,ex)) は 0.43〜0.67 で変動するが、この変動の幾何学的意味が定量化されていない。

### 分析

密度行列空間における誤差ベクトルの幾何学を考える。Stinespring 誤差ベクトル δ_S = ρ_ST - ρ_SCPT と Strang 誤差ベクトル δ_Str = ρ_SCPT - ρ_exact の角度 θ を推定する。

トレース距離が L₁ ノルムであるため厳密なベクトル加法は成立しないが、近似的に：

```
T(ST,ex) ≈ ||δ_S + δ_Str||₁/2
```

L₂ ノルムでの近似（Frobenius ノルム）を用いると：

```
||δ_S + δ_Str||² = ||δ_S||² + ||δ_Str||² + 2·||δ_S||·||δ_Str||·cos(θ)
```

ここで T(ST,ex)² ≈ T(ST,SCPT)² + T(SCPT,ex)² + 2·T(ST,SCPT)·T(SCPT,ex)·cos(θ_approx)

各 dt での推定角度（L₂ 近似）：

| dt | T(ST,ex) | T(ST,SCPT) | T(SCPT,ex) | cos(θ_approx) | θ_approx |
|----|---------|-----------|-----------|---------------|---------|
| 2.00 | 1.103e-3 | 3.960e-4 | 1.242e-3 | -0.604 | 127.2° |
| 1.00 | 2.670e-4 | 1.986e-4 | 3.078e-4 | -0.651 | 130.6° |
| 0.50 | 7.586e-5 | 9.930e-5 | 7.677e-5 | -0.667 | 131.8° |
| 0.20 | 3.303e-5 | 3.970e-5 | 1.228e-5 | -0.652 | 130.7° |

誤差ベクトル間の角度は約 127°〜132° でほぼ安定している。これは Stinespring 誤差と Strang 誤差が密度行列空間で**ほぼ逆向き**（180° に近い）であることを意味する。

cos(θ) ≈ -0.65 は部分的な相殺を表しており、完全な逆方向（cos(θ) = -1）ではないため、相殺比が 0 にはならない。

### 推奨修正

1. トレース距離の余弦定理（law of cosines）による角度推定を検証スクリプトに追加
2. 各 dt での角度の安定性を確認
3. cos(θ) が dt に対してほぼ一定であることを定量的に示す

## 改善点3（分析ギャップ）：ST vs Exact の漸近 Rate(T) の未確認

### 症状

ST vs Exact の Rate(T) が dt=0.5→0.2 で **0.91 < 1.0** になっている。理論的には dt→0 で Rate(T)→1.0 であるべきだが、現在のデータ範囲（dt_min=0.2）では漸近領域に達していない可能性がある。

### 分析

Rate(T) < 1.0 の原因は**相殺比の非単調性**にある。相殺比が dt=0.5 で最小（0.431）→ dt=0.2 で増加（0.635）するため、T(ST,ex) の減少率が個々の成分の減少率を下回る。

漸近的には、dt→0 で：
- T(ST,SCPT) ∝ dt（支配項）
- T(SCPT,ex) ∝ dt²（無視可能）
- T(ST,ex) → T(ST,SCPT)（Strang 成分が無視可能になると相殺が消失）
- Rate(T) → 1.0

しかし、この遷移が完了する dt 値は未知。

dt=0.2 での Stinespring/Strang 比 = T(ST,SCPT)/T(SCPT,ex) = 3.970e-5/1.228e-5 = 3.23

Stinespring が Strang の ~3 倍であり、まだ遷移領域にある。完全な漸近領域（Stinespring >> Strang）には dt ≤ 0.1 が必要と推定される。

### 推奨修正

1. **dt=0.1（n_steps=100）を追加**して漸近挙動を確認
2. dt=0.1 での予測値：
   - T(ST,SCPT) ≈ 1.985e-04 × 0.1 = 1.985e-05
   - T(SCPT,ex) ≈ 3.069e-04 × 0.01 = 3.069e-06
   - Stinespring/Strang 比 ≈ 6.47（漸近領域に近い）
   - Rate(T) for dt=0.2→0.1: 0.95〜1.05 の範囲と予測
3. 計算時間の増加は ~2 分（許容範囲）

## シミュレータコードの検証結果

### QuditGKSLSimulator._trotter_step() ✅

回文順（palindromic）Lindblad 積は正しく実装されている：

```
rho → U_H_half @ rho @ U_H_half†
    → E_1(dt/2) → E_2(dt/2) → ... → E_26(dt/2)    [順方向]
    → E_26(dt/2) → ... → E_2(dt/2) → E_1(dt/2)    [逆方向]
    → U_H_half @ rho @ U_H_half†
```

### stinespring_unitary_from_lindblad() ✅

U = exp(-i·√dt·G) where G = [[0, L†], [L, 0]]。
展開して E(ρ) = ρ + dt·(LρL† − ½{L†L, ρ}) + O(dt²) を確認。

### _symmetric_classical_product_trotter_simulate() ✅

SCPT は ST と同一の回文順構造を正確に再現し、Stinespring 近似の代わりに正確なチャネル指数関数 `expm_multiply(L_D_alpha * (dt/2), vec)` を使用。Lindblad 演算子の順序も `build_lindblad_operators()` からの決定論的順序で一致。

### ClassicalGKSLSimulator ✅

`expm_multiply(L_super, vec_0, ...)` による厳密解。Lindblad–GKS 定理により CPTP 性が構造的に保証されている。
