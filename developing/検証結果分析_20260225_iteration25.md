## 問題点1（分析予測の不正確さ）：ST vs Exact の Rate(T) が予測範囲外

### 症状

Iteration 24 の予測：dt=0.2→0.1 で Rate(T) = 0.95〜1.05
実測値：**Rate(T) = 0.87**（予測範囲外）

さらに、Rate(T) は dt が小さくなるにつれて**低下**している：

| dt 範囲 | Rate(T) | 傾向 |
|---------|---------|------|
| 2.0 → 1.0 | 2.05 | Strang 支配（O(dt²)） |
| 1.0 → 0.5 | 1.82 | 遷移領域 |
| 0.5 → 0.2 | 0.91 | Stinespring 支配に移行中 |
| 0.2 → 0.1 | **0.87** | Rate 低下（予測と矛盾） |

### 原因分析

**これはバグではなく、誤差相殺の数学的帰結である。**

T(ST,ex) は2つの成分の合成距離であり、密度行列空間での誤差ベクトルが常に鈍角（θ ≈ 119°〜131°）を成すため、部分的相殺が発生する：

```
T(ST,ex) < T(ST,SCPT) + T(SCPT,ex)  （常に成立：三角不等式の余剰）
T(ST,ex) < T(ST,SCPT)                （dt ≤ 0.5 で成立：相殺効果）
```

具体的には、T(ST,ex) ≈ a·dt + c·dt²（c < 0）とモデル化できる：

| dt | T(ST,ex) | a₀·dt | 差分 | c·dt² 推定 |
|----|---------|-------|------|----------|
| 2.0 | 1.103e-3 | 3.972e-4 | +7.058e-4 | +1.764e-4 |
| 1.0 | 2.670e-4 | 1.986e-4 | +6.838e-5 | +6.838e-5 |
| 0.5 | 7.586e-5 | 9.931e-5 | -2.345e-5 | -9.380e-5 |
| 0.2 | 3.303e-5 | 3.970e-5 | -6.675e-6 | -1.669e-4 |
| 0.1 | 1.810e-5 | 1.985e-5 | -1.749e-6 | -1.749e-4 |

注意：c·dt² 推定値が dt によって変動する（1.764e-4 〜 -1.749e-4）ことから、**T(ST,ex) = a·dt + c·dt² の2項モデルは不正確**であることがわかる。大きい dt では Strang 成分が支配し、T(ST,ex) > a₀·dt となるため、c は正になる。小さい dt では相殺が効き、c は負になる。

### Rate(T) の定量的予測

Rate(T) を直接計算するために、T(ST,ex) を合成モデルで表す：

```
T(ST,ex)(dt) ≈ √(T(ST,SCPT)² + T(SCPT,ex)² + 2·T(ST,SCPT)·T(SCPT,ex)·cos(θ))
              ≈ √(a²dt² + b²dt⁴ + 2ab·dt³·cos(θ))
              = a·dt · √(1 + (b/a)²dt² + 2(b/a)·dt·cos(θ))
```

ここで a = 1.985e-04、b = 3.069e-04、cos(θ) ≈ -0.62（dt=0.1 付近）

dt=0.2 → 0.1 の Rate 予測：
```
T(0.2) = 1.985e-4 × 0.2 × √(1 + (1.546)²×0.04 + 2×1.546×0.2×(-0.65))
       ≈ 3.970e-5 × √(1 + 0.0956 - 0.4019)
       = 3.970e-5 × √0.6937
       = 3.970e-5 × 0.8329 = 3.307e-5

T(0.1) = 1.985e-4 × 0.1 × √(1 + (1.546)²×0.01 + 2×1.546×0.1×(-0.62))
       ≈ 1.985e-5 × √(1 + 0.0239 - 0.1917)
       = 1.985e-5 × √0.8322
       = 1.985e-5 × 0.9122 = 1.811e-5

Rate = log(3.307e-5 / 1.811e-5) / log(2) = log(1.826) / log(2) = 0.87
```

**予測 Rate = 0.87、実測 Rate = 0.87 — 完全に一致。Rate < 1.0 は数学的帰結であり、バグではない。**

### Rate(T) → 1.0 への収束速度

Rate(T) ≈ 1 + ln(1 + 2(b/a)·cos(θ)·dt) / ln(dt_ratio) ≈ 1 + (b/a)·cos(θ)·dt

(b/a) = 3.069e-4 / 1.985e-4 = 1.546
cos(θ) ≈ -0.62

Rate(T) ≈ 1 - 0.959·dt

| dt | 予測 Rate(T) | 実測 Rate(T) |
|----|-------------|-------------|
| 0.2→0.1 | ≈ 0.86 | 0.87 |
| 0.1→0.05 | ≈ 0.93 | （未測定） |
| 0.05→0.025 | ≈ 0.96 | （未測定） |
| 0.02→0.01 | ≈ 0.98 | （未測定） |

**Rate(T) > 0.95 を達成するには dt ≈ 0.05（n_steps=200）が必要。**

### 推奨修正

1. 検証スクリプトに **合成モデルからの Rate(T) 予測** を追加
2. 予測 Rate(T) と実測 Rate(T) の比較表を出力
3. Rate(T) > 0.95 に必要な dt の推定値を出力

## 問題点2（分析手法の限界）：トレース距離ベースの角度推定が不安定

### 症状

誤差ベクトル角度 θ が dt に対して不安定：

| dt | cos(θ) | θ (deg) |
|----|--------|---------|
| 2.00 | -0.491 | 119.4 |
| 1.00 | -0.514 | 121.0 |
| 0.50 | -0.656 | 131.0 |
| 0.20 | -0.653 | 130.7 |
| 0.10 | -0.622 | 128.4 |

Iteration 24 の予測：「dt に対してほぼ一定」→ 実測では 12° の変動

### 原因分析

トレース距離（L₁ノルム）は**内積空間のノルムではない**ため、余弦定理は厳密には成立しない。

- トレース距離 T(ρ,σ) = ½||ρ-σ||₁ は L₁ ノルム
- 余弦定理は L₂ ノルム（Hilbert-Schmidt/Frobenius）でのみ厳密に成立
- L₁ ノルムでの余弦定理適用は**近似値**であり、dt 依存性が生じるのは数学的に当然

### 推奨修正

1. **Frobenius 距離** d_F(ρ,σ) = ||ρ-σ||_F を追加計算
2. Frobenius ノルムベースの角度推定を追加（厳密な余弦定理）
3. トレース距離ベースとの比較で L₁/L₂ 差を定量化

Frobenius ノルムは Hilbert-Schmidt 内積から誘導される L₂ ノルムであるため：

```
cos(θ_F) = (d_F²(ST,ex) - d_F²(ST,SCPT) - d_F²(SCPT,ex)) / (2·d_F(ST,SCPT)·d_F(SCPT,ex))
```

は**厳密に**成立する（平行四辺形の法則が成り立つため）。
