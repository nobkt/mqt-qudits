## 問題点1（重大）：合成モデルのノルム選択誤り

### 症状

Part 6f のベクトル合成モデルがトレース距離の平均角度を使用しており、精度が低い：

| dt | T_model | T_observed | 相対誤差 |
|----|---------|-----------|---------|
| 2.00 | 1.0431e-03 | 1.1029e-03 | 5.42% |
| 1.00 | 2.4872e-04 | 2.6698e-04 | 6.84% |
| 0.50 | 8.2449e-05 | 7.5858e-05 | **8.69%** |
| 0.20 | 3.4008e-05 | 3.3027e-05 | 2.97% |
| 0.10 | 1.8233e-05 | 1.8097e-05 | 0.75% |

最大誤差 8.69%。合成 Rate(T) 予測（Part 6h）ではさらに悪化：

| dt 範囲 | Rate モデル | Rate 実測 | Δ |
|---------|-----------|----------|------|
| 2.0 → 1.0 | 2.0682 | 2.0465 | +0.0218 |
| 1.0 → 0.5 | 1.5930 | 1.8154 | **-0.2224** |
| 0.5 → 0.2 | 0.9665 | 0.9075 | +0.0590 |
| 0.2 → 0.1 | 0.8994 | 0.8679 | +0.0315 |

dt=1.0→0.5 で Δ=-0.2224。予測として不十分。

### 根本原因

ベクトル合成モデル `T_model(dt) = a₀·dt·√(1 + r²dt² + 2r·dt·cos(θ_mean))` は余弦定理をトレース距離（L₁ ノルム）に適用している。しかし：

1. **余弦定理はトレース距離では近似的にしか成立しない**（L₁ ノルムは内積から誘導されないため）
2. **トレース距離ベースの角度 θ_T は dt 依存**（119°〜131° の 12° 変動）
3. **平均角度 cos(θ_mean) = -0.5871 はどの dt でも正確ではない**：大きい dt では過大評価、中間の dt では過小評価

→ 余弦定理の適用ノルムを**トレース距離からFrobenius距離に変更する必要がある**。

### Frobenius ベース合成モデルでの検証

## 問題点2（分析不足）：T/d_F 比率の dt 依存性が未分析

### 症状

トレース距離とFrobenius距離の比率 T/d_F が個別成分では安定だが合成では不安定：

**個別成分（安定）：**

| dt | T/d_F (Stinespring) | T/d_F (Strang) |
|----|-------------------|---------------|
| 2.00 | 0.890839 | 0.911363 |
| 1.00 | 0.891050 | 0.911684 |
| 0.50 | 0.891100 | 0.911763 |
| 0.20 | 0.891114 | 0.911785 |
| 0.10 | 0.891116 | 0.911788 |

- Stinespring: 変動 0.031%（0.890839 → 0.891116）
- Strang: 変動 0.047%（0.911363 → 0.911788）

**合成（不安定）：**

| dt | T/d_F (ST vs exact) |
|----|-------------------|
| 2.00 | 0.945657 |
| 1.00 | 0.962242 |
| 0.50 | **0.813769** |
| 0.20 | 0.860172 |
| 0.10 | 0.882184 |

- **変動 18.2%**（0.8138 → 0.9622）

### 原因分析

個別誤差成分の T/d_F 比率が異なる：
- Stinespring 誤差: T/d_F ≈ 0.8911
- Strang 誤差: T/d_F ≈ 0.9118

この差は、各誤差行列 δ = ρ₁ − ρ₂ の固有値スペクトル形状の違いに起因する。トレース距離は固有値の絶対値和（L₁）、Frobenius 距離は固有値の二乗和の平方根（L₂）であるため、スペクトル形状が異なれば比率も異なる。

合成誤差の T/d_F が不安定になる理由：
- 大きい dt: Strang 成分が支配 → T/d_F ≈ 0.91（Strang の比率に近い）
- 小さい dt: Stinespring 成分が支配 → T/d_F ≈ 0.89（Stinespring の比率に近い）
- 中間の dt: 二つの成分が干渉 → T/d_F は非自明な値

合成 T/d_F がクロスオーバー付近（dt≈0.5）で最小値 0.814 になるのは、異なる固有値分布を持つ二つの誤差行列が部分的に相殺する際に、L₁ と L₂ の振る舞いが最も乖離するためである。

### Rate(T) と Rate(d_F) の乖離の原因

Rate(T) = 0.87（dt=0.2→0.1）だが Rate(d_F) = 0.90 である。この差 0.03 は、T/d_F 比率の dt 依存性によるもの：

```
Rate(T) ≈ Rate(d_F) + d(ln(T/d_F))/d(ln(dt)) × Rate(T)/Rate(d_F)
```

T/d_F 比率が dt とともに増加（Stinespring 支配への遷移）しているため、Rate(T) < Rate(d_F) となる。

## 問題点4（軽微）：変数存在チェックの不適切な実装

### 症状

Part 6f（line 1388-1389）で変数の存在チェックに `"a0_stine" in dir()` を使用：

```python
a0_val = a0_stine if "a0_stine" in dir() else a_stine
b0_val = b0_strang if "b0_strang" in dir() else b_strang
```

`dir()` はモジュールレベルの名前を返すため、ローカル変数のチェックには不適切。現在の制御フローでは常に `a0_stine` が定義されているため動作するが、将来の変更でバグになる可能性がある。
