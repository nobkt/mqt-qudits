## 2. 数学的実装の検証

### 2.1 Stinespring dilation の実装正確性

`stinespring_utils.py` の実装を厳密に検証した。

**生成子の構成**:
```
G = [[0, L†], [L, 0]]  (2d_sys × 2d_sys)
θ = √dt
U = exp(-iθG)
```

ランク1の Lindblad 演算子 L = √γ |a⟩⟨b| に対して、固有空間解析を行うと:

- K₀ = I - (1-cos(√(dtγ))) |b⟩⟨b|
- K₁ = -i sin(√(dtγ)) |a⟩⟨b|

CPTP条件の検証: K₀†K₀ + K₁†K₁ = I ✓

チャネル展開:
```
E(ρ) = K₀ρK₀† + K₁ρK₁†
     = ρ + dt(LρL† - ½{L†L, ρ}) + O(dt²)
```

**O(dt²) 誤差の定量的分析**:
- cos²(α) = 1 - dtγ + (dtγ)²/3 + O(dt³γ³)
- exp(-γdt) = 1 - dtγ + (dtγ)²/2 + O(dt³γ³)
- 個体群減衰の誤差: |(1/3 - 1/2)(dtγ)²| = (dtγ)²/6 （チャネルあたり・ステップあたり）

**グローバル誤差のスケーリング**: n チャネル × T/dt ステップ × O(dt²γ²)/チャネル/ステップ = O(nγ²Tdt) = **O(dt)**

実装は数学的に正しい。 ✓

### 2.2 Trotter 分割の構造

```
Φ_step(ρ) = U_H(dt/2) · [∏_{α=1..n} E_α(dt/2)] · [∏_{α=n..1} E_α(dt/2)] · U_H(dt/2)
```

- **Strang H-D 分割**: O(dt³)/ステップ → 全体 O(dt²)
- **回文順序 Lindblad 積**: Lie-Trotter 交換子誤差の 2 次消去 → O(dt³)/ステップ
- **Stinespring 近似**: O(dt²)/チャネル/ステップ → **全体 O(dt) が支配的**

実装は正しく、3段階の近似構造が一貫している。 ✓

### 2.6 Lindblad 演算子の構成

| チャネル | 演算子 | レート | 数（N=4） | 物理過程 |
|---------|--------|-------|----------|---------|
| TTA (ch1) | √(γ_TTA/2) \|2⟩_i⟨1\| ⊗ \|0⟩_j⟨1\| | γ_TTA/2 | 6 | T₁+T₁→S₁+S₀ |
| TTA (ch2) | √(γ_TTA/2) \|0⟩_i⟨1\| ⊗ \|2⟩_j⟨1\| | γ_TTA/2 | (上記に含む) | T₁+T₁→S₀+S₁ |
| 蛍光 | √Γ_fl \|0⟩⟨2\| | Γ_fl | 4 | S₁→S₀ |
| 燐光 | √Γ_ph \|0⟩⟨1\| | Γ_ph | 4 | T₁→S₀ |
| 内部変換 | √k_IC \|0⟩⟨2\| | k_IC | 4 | S₁→S₀ |
| ISC S→T | √k_ISC_ST \|1⟩⟨2\| | k_ISC_ST | 4 | S₁→T₁ |
| ISC T→S | √k_ISC_TS \|0⟩⟨1\| | k_ISC_TS | 4 | T₁→S₀ |

合計: 2×3(TTA) + 5×4(単一サイト) = 26 演算子 ✓

**重複する遷移演算子に関する分析**:
- 蛍光 (Γ_fl) と内部変換 (k_IC): 同一遷移 |0⟩⟨2|
- 燐光 (Γ_ph) と ISC T→S (k_ISC_TS): 同一遷移 |0⟩⟨1|

これらは数学的に √(γ₁+γ₂)|a⟩⟨b| に統合可能。ただし、分離したまま維持する方が Stinespring 近似の O(dt) 誤差係数が**小さくなる**。理由:

- 分離: Σγ² = γ₁² + γ₂² 
- 統合: (γ₁+γ₂)² = γ₁² + 2γ₁γ₂ + γ₂² > γ₁² + γ₂²

具体例（蛍光 Γ_fl=0.01 + IC k_IC=0.005）:
- 分離: 0.01² + 0.005² = 1.25×10⁻⁴
- 統合: 0.015² = 2.25×10⁻⁴（1.8倍大きい）

**結論**: 現在の「冗長な」構造は、Stinespring 近似精度の観点で**より良い選択**であり、バグではない。
