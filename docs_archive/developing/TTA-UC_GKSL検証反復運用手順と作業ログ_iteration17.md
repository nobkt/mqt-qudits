しかし、以下の検証方法論上の問題を発見した:

### 問題1: Test C の予測モデル F=(1-ε)^n が根本的に不正確

数値検証により、1ステップあたりの実効 ε が各ステップで減少することを確認。
ε(step 1) = 0.1004 → ε(step 10) = 0.0791（21%の減少）。
これは脱分極チャネルの「収穫逓減」効果（状態が最大混合状態に近づくほど追加の
脱分極の影響が小さくなる）によるものであり、一定 ε 仮定は不成立。

### 問題2: Test A のトレードオフ探索は不適切な目的設定

追加検証（p_depol = 1e-5, 1e-4）の結果、すべての実用的ノイズレベルにおいて
ノイズ不忠実度がTrotter不忠実度を大幅に上回ることを確認。
このシステムのTrotter近似は極めて高精度であり、「ノイズ-Trotterトレードオフ」は
実用パラメータ範囲で存在しない。
