## 理論・設計の正当性検証

### Stinespring dilation の実装確認

**構成:**
```
G = [[0, L†], [L, 0]]
U = expm(-i √dt G)
```

展開すると:
- K₀ = ⟨0|U|0⟩ ≈ I - dt/2 L†L + O(dt²)
- K₁ = ⟨1|U|0⟩ ≈ -i√dt L + O(dt^{3/2})

Kraus map: E(ρ) = K₀ ρ K₀† + K₁ ρ K₁†
         ≈ ρ + dt(LρL† - ½{L†L, ρ}) + O(dt²)

これは**1次近似**であり、正確なリンドブラッドチャネル exp(D·dt) とは O(dt²) の誤差がある。
ただし、トレース保存は厳密（K₀†K₀ + K₁†K₁ = I from unitarity of U）。

**`apply_stinespring_to_density_matrix`の検証:**
- `np.kron(env0, rho)` で `|0⟩⟨0| ⊗ ρ` を構成 ✅
- `rho_prime = U @ rho_ext @ U†` ✅
- `rho_out = rho_prime[:d,:d] + rho_prime[d:,d:]` は正確な部分トレース ✅

**結論:** Stinespring dilation は正しく実装されている。

### 2次対称Trotter分解の検証

**分解構造:**
```
exp(L dt) ≈ exp(L_H dt/2) ∏_α exp(L_D_α dt) exp(L_H dt/2) + O(dt³)
```

- ハミルトニアン-散逸体分割: 2次対称（O(dt³) per step）
- 散逸チャネル間の分割: 1次逐次適用（O(dt²) per step）
- Stinespring近似: 1次（O(dt²) per channel per step）

**全体の per-step 誤差: O(dt²)**

dt=1.0, t_max=5.0 での検証結果:
- classical vs qudit fidelity: 0.999995（infidelity ≈ 5×10⁻⁶）
- classical entropy: 0.030570 vs qudit entropy: 0.030047（差 ≈ 0.052%）

これはO(dt²)の理論的期待と整合的である。

### ノイズモデルの検証

**Qudit (d=3):**
- 脱分極: Weyl-Heisenberg X^a Z^b 演算子（d²-1=8 個の非恒等演算子）
- ディフェージング: 計算基底への確率的射影 P_k = |k⟩⟨k| (k=0,1,2)

**Qubit (d=4):**
- 脱分極: 2-qubitパウリ演算子（d²-1=15 個の非恒等演算子）
- ディフェージング: 4次元計算基底への確率的射影 P_k = |k⟩⟨k| (k=0,1,2,3)
  - k=3 (|11⟩) への射影は禁止状態リーケージを引き起こす
- 熱緩和: 2-qubit Kraus分解による T1 減衰

ノイズチャネルの理論的正しさ:
- 脱分極: Σ_k K_k†K_k = (1-p)I + p/d² Σ P_k = I ✅（トレース保存）
- ディフェージング: (1-p)I + p Σ P_k = I ✅
- 熱緩和: K_00†K_00 + K_01†K_01 + K_10†K_10 + K_11†K_11 = I ✅

## 発見された問題点

### 問題1（重要）: ハミルトニアン転送ゲート後のディフェージングノイズの欠落

**対象ファイル:**
- `tutorials/qudit_gksl_shot_simulator.py` (QuditGKSLNoisyShotSimulator)
- `tutorials/qubit_gksl_shot_simulator.py` (QubitGKSLNoisyShotSimulator)

**現象:**

`_trotter_step_trajectory` メソッドにおいて、ノイズの適用が以下のように非対称:

| ゲート種別 | 脱分極 | ディフェージング |
|-----------|--------|--------------|
| ハミルトニアン転送ゲート（2サイト） | ✅ pair depol | ❌ なし |
| リンドブラッド Stinespring（1サイト） | ✅ single depol | ✅ single dephasing |
| リンドブラッド Stinespring（2サイト） | ✅ pair depol | ✅ single dephasing ×2 |

ハミルトニアン転送ゲート（最近接分子間の2体相互作用）は、
リンドブラッド Stinespring ゲート（同じく2体演算）と同種の量子ゲートであるにもかかわらず、
ディフェージングノイズが適用されていない。

**理論的根拠:**

実際の量子回路では:
- ハミルトニアン転送 = 2-qubit/qudit ゲート → 脱分極 + ディフェージング
- Stinespring チャネル = 2-qubit/qudit ゲート → 脱分極 + ディフェージング

両方とも物理的な量子ゲート操作であり、同じノイズモデルが適用されるべき。
現在のコードでは、Stinespring ゲートのみにディフェージングが適用されており、
ハミルトニアン転送ゲートのディフェージングが欠落している。

**影響:**

- ノイズの過小評価: ハミルトニアン部分のゲートノイズが不完全
- Trotterステップあたり 2回 × 3近接対 = 6回のディフェージング欠落
- 合計: 5ステップ × 12回 = 60回のディフェージングが適用されていない

**修正方針:**

ハミルトニアン転送ゲート後にも、リンドブラッドペアゲートと同様に
ディフェージングノイズを適用する。qubit/qudit両方に対称的に適用。

**深刻度: 重要**（物理モデルの完全性・一貫性）

### 問題2（中程度）: 検証スクリプトのqubit/quditノイズモデル非対称

**対象ファイル:** `tutorials/run_tta_uc_gksl_verification.py`

**現象:**

| ノイズ種別 | qudit_noisy_shot | qubit_noisy_shot |
|-----------|-----------------|-----------------|
| 脱分極 (p_depol) | 0.01 | 0.01 |
| ディフェージング (p_dephasing) | 0.005 | 0.005 |
| 熱緩和 (T1, t_gate) | ❌ なし | ✅ T1=50000, t_gate=300 |

qubit_noisy_shot にのみ T1 熱緩和が含まれているため:
- qubit trace deficit = 33.9%（T1+depol+dephasing の複合効果）
- qudit trace deficit = 0%（リーケージなし）
- fidelity(qudit_noisy, qubit_noisy) = 0.943（ノイズモデル差+符号化差の混合）

**問題点:**

符号化方式の違い（qubit vs qudit）に起因するリーケージ効果と、
T1熱緩和に起因する効果が分離できない。

p_depol=0.01 のみの場合、qubit trace deficit は大幅に減少するはずだが、
T1熱緩和（p_reset≈0.006 per step per qubit）が加わることで 34% もの
リーケージが発生している。

**修正方針:**

qubit_noisy_shot から T1/t_gate パラメータを除去（T1=None）し、
qudit_noisy_shot と完全に同一のノイズパラメータ（脱分極+ディフェージング）
で比較する。これにより符号化方式の違いのみに起因する効果を定量化できる。

T1 熱緩和の効果を検証したい場合は、ユーザーが `QubitGKSLNoisyShotSimulator`
を直接使用してカスタムパラメータで実行できる。

**深刻度: 中程度**（テスト設計の公平性）
