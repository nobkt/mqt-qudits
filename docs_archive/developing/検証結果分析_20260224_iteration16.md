## 2. コード実装の数学的正確性検証

### 2.1 Stinespring構成の検証

**検証対象**: `stinespring_utils.py::stinespring_unitary_from_lindblad`

生成子 G = [[0, L†], [L, 0]] は Hermitian であり、U = exp(-iθG) (θ=√dt) は
ユニタリ。部分トレースによるチャネルは:

```
E(ρ) = Tr_anc[U(|0⟩⟨0|⊗ρ)U†]
     = ρ + dt·(LρL† − ½{L†L, ρ}) + O(dt²)
```

**結果**: 数学的に正確。1次の項は厳密GKSL散逸子に一致する。O(dt²) の補正は
dt=1.0, γ_TTA/2=0.025 の場合、sin²(√(dt·γ)) vs dt·γ の差は約 0.24% であり
無視可能。Test 2 の結果（F > 0.9999）はこの分析と整合する。✅

### 2.2 GKSL超演算子の検証

**検証対象**: `stinespring_utils.py::build_gksl_superoperator`

列優先（Fortran order）ベクトル化を使用:

```
L_H = (-i/ℏ)(I⊗H − H^T⊗I)
L_D = Σ_α [conj(L_α)⊗L_α − 0.5·I⊗L†_αL_α − 0.5·(L†_αL_α)^T⊗I]
```

**結果**: vec(AXB) = (B^T ⊗ A)vec(X) の恒等式に基づいて、各項を検証:
- vec(LρL†) = (L̄ ⊗ L)vec(ρ) ← `np.kron(L_op.conj(), L_op)` ✅
- vec(L†Lρ) = (I ⊗ L†L)vec(ρ) ← `np.kron(I, LdL)` ✅
- vec(ρL†L) = ((L†L)^T ⊗ I)vec(ρ) ← `np.kron(LdL.T, I)` ✅

### 2.3 脱分極チャネルの検証

**DM実装** (`qudit_gksl_noisy_simulator.py`):

```
E(ρ) = (1-p)ρ + (p/d²)·I_{pair}⊗Tr_{pair}[ρ]
```

部分トレースと再構成のテンソル操作を検証。indexing [site] と [N+site] の
対応（ket/bra軸）が正しく、reshape/混合の構成も正確。✅

**ショット実装** (`qudit_gksl_shot_simulator.py`):

Weyl-Heisenberg演算子による確率的脱分極:
- 恒等確率: 1 - p + p/d^4
- 非恒等演算子確率: p/d^4 each

Weyl-Heisenbergツイル恒等式により:
```
(1/d²)Σ_{a,b} (X^aZ^b)M(X^aZ^b)† = Tr(M)·I/d
```

ペアへの拡張も同様に正しい。DM実装と数学的に等価であることを確認。✅

## 3. 検証結果の詳細分析

### 3.1 ノイズによるN_S1成長の定量的説明

**観測事実**: Qudit ノイジーの N_S1 はステップ1で 0.0776 に急増し、
ステップ10で 0.6184 に達する（ノイズレス参照の N_S1=0.0690 の約9倍）。

**理論的説明**:

pair-only モードでは、1 Trotter ステップあたり 12 回のペア脱分極イベントが発生:
- Half Hamiltonian (前半): 3 NN pairs × 1 = 3 回
- TTA Lindblad channels: 3 NN pairs × 2 channels = 6 回
- Half Hamiltonian (後半): 3 NN pairs × 1 = 3 回

各ペア脱分極イベント (p=0.01) は、ペアの状態を I/d²=I/9 で置換する確率 p を持つ。
最大混合状態 I/9 のペアにおける S1 population の寄与:
- d²=9 ペア状態のうち、S1 を含む状態: |S1,S0⟩, |S1,T1⟩, |S1,S1⟩, |S0,S1⟩, |T1,S1⟩ = 5状態
- これらが寄与する S1 population = (2×2 + 1×3) / 9 = 実際には各状態で2分子分の平均

**正確な計算**: 初期状態からの1回のペア脱分極によるΔN_S1 ≈ p × 2/3 ≈ 0.0067。
12回のイベントで ΔN_S1 ≈ 0.080。観測値（ステップ1で 0.0776）と良好に一致。

10ステップ後の N_S1 は指数的な最大混合状態への接近として説明可能:
```
N_S1(t) ≈ N_S1_max × (1 - (1-ε)^t)
```
ε ≈ 0.06（実効脱分極率/ステップ）, N_S1_max = 4/3 ≈ 1.333

N_S1(10) ≈ 1.333 × (1 - 0.94^10) ≈ 1.333 × 0.461 ≈ 0.614

**観測値 0.618** と非常に良く一致する。✅ コードバグではなく、脱分極ノイズモデルの
正常な動作であることを確認。

### 3.2 Qubit禁止状態leakageの定量的説明

**観測事実**: Qubit P_forbidden がステップ10で 0.354 に達する。

**理論的説明**:

Qubit エンコーディング（d=4 per molecule）では、各分子の4状態のうち
|11⟩ = local state 3 が禁止状態。ペア脱分極 E(ρ) = (1-p)ρ + (p/16)I⊗Tr[ρ]
により、各イベントで禁止状態への population 移動が発生する。

辺分子（mol 0, 3）は4回、内部分子（mol 1, 2）は8回のペアイベントを受ける。
1イベントあたりの禁止状態遷移確率 ≈ p × 1/4 = 0.0025。

ステップあたりの総禁止population増加 ≈ 2×(4×0.0025) + 2×(8×0.0025) = 0.060。
10ステップ後: 1 - (1-0.060)^10 ≈ 0.46（理論値）

**観測値 0.354** はこれより低いが、以下の理由で整合的:
1. 禁止状態への遷移は初期状態依存（すでに禁止状態にある population は再利用される）
2. Stinespring チャネルは物理部分空間を保存するため、禁止→物理の「回復」効果がある
3. 相関効果（連続イベント間の非独立性）

### 3.3 Test 4: Qubit raw忠実度が低い理由

**観測事実**: Qubit F(DM, shot) = 0.407 だが F_norm(DM, shot) = 0.991

**理論的説明**: Uhlmann忠実度 F(ρ, σ) = [Tr√(√ρ σ √ρ)]² は、
サブユニットトレースの密度行列に対して、トレースの積に制約される。

DM ノイジー: Tr(ρ_qt) ≈ 0.646
Shot ノイジー: Tr(σ_qt) ≈ 0.636

F_max ≈ Tr(ρ)·Tr(σ) ≈ 0.411

観測値 F = 0.407 は F_max に近く、**内部構造はほぼ一致**していることを示す。
正規化後の F_norm = 0.991 がDM-Shot整合性の適切な指標。

**問題点**: 現在の検証スクリプトは raw F を主指標として報告しており、
誤解を招く可能性がある。サブユニットトレース行列の比較では、常に
正規化忠実度と raw 忠実度の両方を報告し、解釈の注意を付記すべき。

### 3.4 ノイズ-Trotter トレードオフ（未検証の重要課題）

**問題**: Test 1 はノイズレスの Trotter 収束のみテストしている。
ノイジーシミュレーションでは、n_steps を増やすと:
- Trotter誤差は減少: O(dt²) = O((t_max/n_steps)²)
- ノイズ累積は増加: 12n_steps 回の脱分極イベント

最適な n_steps が存在するはずだが、現在の検証では探索されていない。

これは実用上の重要課題であり、iteration 16 で検証すべき。
