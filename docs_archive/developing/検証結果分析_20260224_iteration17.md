## 3. 発見された問題の詳細分析

### 問題1（重要）: Test C の予測モデル F=(1-ε)^n は根本的に不正確

#### 3.1.1 問題の記述

Test C は 1 ステップで ε を測定し、F_predicted = (1-ε)^n_steps でマルチステップの
忠実度を予測している。しかし、実測値は系統的に予測を上回る:

| n_steps | F_predicted | F_actual | Δ |
|---------|-------------|----------|---|
| 5 | 0.5890 | 0.6061 | +0.017 |
| 10 | 0.3470 | 0.3759 | +0.029 |
| 20 | 0.1204 | 0.1624 | +0.042 |
| 50 | 0.0050 | 0.0424 | +0.037 |

Δ は常に正であり、n_steps の増加とともに増大している。

#### 3.1.2 原因の特定: ε(n) は一定ではなく単調減少する

追加の数値検証により、1ステップあたりの実効 ε が各ステップで減少することを確認した:

| Step | F(n) | ε(n) = 1 - F(n)/F(n-1) | F_ratio |
|------|-------|------------------------|---------|
| 1 | 0.8996 | 0.1004 | 0.8996 |
| 2 | 0.8098 | 0.0997 | 0.9003 |
| 3 | 0.7297 | 0.0990 | 0.9010 |
| 4 | 0.6582 | 0.0980 | 0.9020 |
| 5 | 0.5945 | 0.0966 | 0.9034 |
| 6 | 0.5383 | 0.0946 | 0.9054 |
| 7 | 0.4888 | 0.0919 | 0.9081 |
| 8 | 0.4457 | 0.0883 | 0.9117 |
| 9 | 0.4082 | 0.0840 | 0.9160 |
| 10 | 0.3759 | 0.0791 | 0.9209 |

**ε(n) は step 1 の 0.1004 から step 10 の 0.0791 まで 21% 減少している。**

#### 3.1.3 物理的メカニズム

脱分極チャネル E(ρ) = (1-p)ρ + (p/d²)I⊗Tr[ρ] は、状態を最大混合状態に
近づける。状態が最大混合状態に近いほど、追加の脱分極の効果は小さくなる
（「収穫逓減」効果）。

数学的には、脱分極チャネルの不動点は ρ_∞ = I/d^N であり、
F(ρ, ρ_∞) > 0 である。したがって F(n) → F_∞ > 0 であり、
F(n) = (1-ε)^n → 0 とはならない。

簡易モデル F=(1-ε)^n は以下を仮定しているが、いずれも不正確:
1. **一定 ε**: 実際には ε(n) は状態依存で単調減少
2. **F → 0**: 実際には F → F_∞ > 0 (最大混合状態の不動点忠実度)

#### 3.1.4 付随的確認: ε は dt にほぼ依存しない

1 ステップでの ε を異なる dt で測定した結果:

| dt | F_1step | ε |
|------|---------|------|
| 0.20 | 0.8990 | 0.1010 |
| 0.50 | 0.8993 | 0.1007 |
| 1.00 | 0.8996 | 0.1004 |
| 2.00 | 0.8999 | 0.1001 |

dt に対する ε の変動は ~0.1% 以下であり、ノイズチャネルが本質的に dt 非依存
（ゲートノイズとして正しく実装されている）ことを確認。

### 問題2（中程度）: Test A のトレードオフは実用パラメータ範囲で存在しない

#### 3.2.1 問題の記述

Test A は「ノイズ-Trotter トレードオフ」を探索する設計だが、結果は
F(noisy, noiseless) が n_steps とともに単調減少を示し、
トレードオフは発見されなかった。

#### 3.2.2 原因

このシステムの Trotter 近似誤差は極めて小さい:
- n_steps=5 (dt=2.0): F(noiseless, finest_ref) = 0.99986 → Trotter不忠実度 ~1.4×10⁻⁴
- n_steps=10 (dt=1.0): F(noiseless, finest_ref) = 0.99997 → Trotter不忠実度 ~3.2×10⁻⁵

一方、ノイズ不忠実度は:
- p_depol=0.01 の場合: ~0.10 per step (Trotter 誤差の ~700 倍)
- p_depol=1e-4 の場合: ~5×10⁻³ at n=5 (Trotter 誤差の ~35 倍)
- p_depol=1e-5 の場合: ~6×10⁻⁴ at n=5 (Trotter 誤差の ~4 倍)

**追加検証結果**: p_depol = 1e-5 でもノイズが Trotter 誤差を上回り、
F は n_steps 増加で単調減少:

| p_depol | n_steps=5 F(noisy,finest) | n_steps=50 F(noisy,finest) | 単調減少? |
|---------|--------------------------|---------------------------|-----------|
| 1e-5 | 0.99939 | 0.99526 | はい |
| 1e-4 | 0.99510 | 0.95153 | はい |
| 0.01 | 0.60470 | 0.04238 | はい |

#### 3.2.3 結論

この TTA-UC システムの Trotter 近似は非常に高精度であり、
実用的な全ノイズレベルにおいて **最小 n_steps が常に最適** である。
「ノイズ-Trotter トレードオフ」という概念自体はこのシステムでは
実用的に無意味であり、Test A のフレーミングは誤解を招く。

これはコードバグではなく、物理的に正しい結果であるが、
検証テストの目的設定が不適切であった。

### 問題3（軽微）: Test C の多ステップ比較で dt が変動する混乱

Test C は t_max=10 固定で n_steps を変えるため、dt も変わる。
ε を dt=1.0 で測定して (1-ε)^5 (dt=2.0) や (1-ε)^50 (dt=0.2) を予測している。
これは ε が dt 非依存であること（問題1 の 3.1.4 で確認済み）を暗黙に仮定しているが、
スクリプト中にこの仮定の明示や検証がない。

## 4. 修正方針

### 4.1 Test C の修正: Per-Step ε 追跡

- F=(1-ε)^n の予測を**削除**し、ステップごとの ε(n) を直接測定
- ε(n) の単調減少を明示的に示す
- 理論的 ε（per-event infidelity × events/step）との比較を維持
- dt 依存性の検証を追加（異なる dt での ε 測定）

### 4.2 Test A の修正: 明確な結論の導出

- F(noisy, finest_ref) だけでなく F(noiseless, finest_ref) も報告
- Trotter不忠実度とノイズ不忠実度を分離して比較
- 「最小 n_steps が最適」という結論を明確に導出
- 複数 p_depol でのスイープを追加

### 4.3 Tests B, D: 変更なし

Test B（ノイズバジェット分解）と Test D（Qubit 忠実度追跡）は
方法論的に正確であり、変更の必要はない。

## 5. 総合評価

**Iteration 16 のコード実装は数学的に正確であり、バグは存在しない。**

発見された問題は検証スクリプトの**方法論**に限定される:
1. Test C の予測モデルが不正確（ε 一定の仮定が不成立）
2. Test A の目的が達成不可能（実用パラメータでトレードオフなし）

これらはシミュレーション結果の**解釈**に影響するが、
シミュレーション結果自体は物理的に正しい。
