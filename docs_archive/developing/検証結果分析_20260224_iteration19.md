## 2. 発見された問題

### 問題1（重大）: Stinespring近似誤差の分離方法が数学的に不正確

**現状**: Test E の「Stinespring近似」列は以下の減算で算出されている：

```python
infid_stine = infid_total - infid_trotter
```

ここで：
- `infid_total = 1 - F(ST(n), exact)` : 全体誤差（Stinespring+Trotter vs 正確解）
- `infid_trotter = 1 - F(ST(n), ST(100))` : 「Trotter誤差」（ST(n) vs 最精密ST参照解）

**問題点**:

**(a) 忠実度不忠実度は加法的でない**

忠実度不忠実度 (1−F) は距離メトリクスではなく、一般に加法的に分解できない。正しくは Bures 距離 `d_B(ρ,σ) = √(2(1−√F(ρ,σ)))` が三角不等式を満たすメトリクスであり、

```
d_B(ST(n), exact) ≤ d_B(ST(n), ST(100)) + d_B(ST(100), exact)
```

は成立するが、不忠実度の差がStinespring近似誤差に等しいとは限らない。

**(b) "Trotter-only" 測定がTrotter誤差だけを測定していない**

`1 − F(ST(n), ST(100))` は、2つの Stinespring+Trotter 近似の**差**を測定している。ST(n) と ST(100) は同じ Stinespring 近似手法を使うが、dt が異なるため Stinespring 近似誤差も異なる。したがって、この測定値は **Trotter 分割誤差と Stinespring 近似誤差の差の両方**を含む。

**数値的証拠**:

| n_steps | dt   | infid_total | infid_trotter | infid_stinespring（減算値） |
|---------|------|-------------|---------------|---------------------------|
| 5       | 2.00 | 1.554e-04   | 1.402e-04     | 1.528e-05                 |
| 10      | 1.00 | 3.942e-05   | 3.184e-05     | 7.581e-06                 |
| 20      | 0.50 | 9.899e-06   | 6.264e-06     | 3.636e-06                 |
| 50      | 0.20 | 1.452e-06   | 2.505e-07     | 1.202e-06                 |

n_steps=50 (dt=0.2) では减算値の infid_stinespring (1.202e-06) が infid_trotter (2.505e-07) の約5倍を占める。dt が小さくなると Stinespring 項が支配的になるように見えるが、この分離が数学的に厳密でないため、個々の値の定量的信頼性は低い。

**修正方針**: 減算による分離を廃止し、適切な比較対象（古典 Trotter）を用いた独立測定に置き換える。

### 問題2（重大）: 忠実度ベースの収束次数が真の誤差スケーリングを隠蔽

**現状**: Test E の収束次数分析は忠実度不忠実度 (1−F) のみに基づいており、平均収束次数 2.02 と報告されている。これは「Stinespring+Trotter の全体誤差は O(dt²) で収束する」と読めるが、これは**不正確**である。

**問題点**:

忠実度不忠実度とトレース距離の関係は Fuchs–van de Graaf 不等式：

```
1 − √F ≤ T ≤ √(1−F)

整理すると: T² ≤ 1−F ≤ 2T − T²
```

微小誤差（T → 0）の場合、下界が支配的で **1−F ≈ T²** が成立する。つまり、**忠実度不忠実度の収束次数はトレース距離の収束次数の約2倍を示す**。

**理論的予測**:

Stinespring dilation の展開：

```
E_α(ρ, dt) = ρ + dt·D_α[ρ] + c₂·dt² + O(dt^{5/2})
exp(D_α dt)[ρ] = ρ + dt·D_α[ρ] + (dt²/2)·D_α²[ρ] + O(dt³)
```

- Stinespring 近似のステップ当たり誤差: O(dt²)（密度行列のノルム差）
- 累積誤差（T/dt ステップ）: (T/dt) × O(dt²) = O(dt)（トレース距離）
- 忠実度不忠実度: O(T²) = O(dt²) （∵ 1−F ≈ T² の関係）

**数値的証拠**:

N_S1 ポピュレーション差（線形汎関数であるためトレース距離に比例）の dt 依存性：

| n_steps | dt   | N_S1(ST) | N_S1(exact) | |ΔN_S1| |
|---------|------|----------|-------------|---------|
| 5       | 2.00 | 0.06779  | 0.06971     | 0.00192 |
| 10      | 1.00 | 0.06904  | 0.06971     | 0.00067 |
| 20      | 0.50 | 0.06945  | 0.06971     | 0.00026 |
| 50      | 0.20 | 0.06962  | 0.06971     | 0.00009 |

収束次数（|ΔN_S1| の dt に対する次数）：

| dt 範囲 | 比率 | 収束次数 |
|---------|------|---------|
| 2.0 → 1.0 | 2.87 | 1.52 |
| 1.0 → 0.5 | 2.58 | 1.37 |
| 0.5 → 0.2 | 2.89 | 1.16 |

**N_S1 差の収束は O(dt²) ではなく O(dt^{1.0〜1.5})** であり、小さい dt ほど O(dt) に近づく。これは Stinespring 近似の累積誤差が O(dt) であるという理論予測と整合的。

忠実度不忠実度が O(dt²) と報告されたのは、1−F ≈ T² の関係により収束次数が2倍に見えるためであり、**真の状態間距離は O(dt) でしか収束しない**。

この発見は実用上重要である：dt=0.2 で忠実度 0.9999985（不忠実度 1.45×10⁻⁶）と報告されているが、トレース距離はその√ 程度（～1.2×10⁻³）であり、ポピュレーション差 |ΔN_S1| = 8.7×10⁻⁵ と整合する。

### 問題3（中程度）: Trotter収束次数の異常値が未分析

**現状**: Trotter 収束次数表で dt 0.5→0.2 の値が 3.51 と報告されているが、これについてのコメントがない。

| dt 範囲 | 全体収束次数 | Trotter 収束次数 |
|---------|------------|-----------------|
| 2.0 → 1.0 | 1.98 | 2.14 |
| 1.0 → 0.5 | 1.99 | 2.35 |
| 0.5 → 0.2 | 2.09 | **3.51** |

**原因分析**:

`infid_trotter = 1 − F(ST(n), ST(100))` は ST(n) と ST(100) の差であり、n=50 (dt=0.2) では ST(50) と ST(100) が非常に近い。具体的に：

- infid_trotter(n=20): 6.264×10⁻⁶
- infid_trotter(n=50): 2.505×10⁻⁷

この差は実質的にゼロに近づいているため、見かけの収束次数が理論値(2.0)から大きく逸脱する。ST(100) 自体が有限の Stinespring 近似誤差を持つため（infid(ST(100), exact) = 2.44×10⁻⁷）、ST(50) と ST(100) の差が O(dt²) の理論スケーリングに従わなくなっている。

**修正方針**: Trotter-only の収束次数算出は ST(n) vs ST(100) ではなく、独立した参照解（古典 Trotter）を用いて測定する。

## 4. Iteration 19 の作業計画

### 修正1: トレース距離の追加

`trace_distance(ρ, σ) = ½ ||ρ − σ||₁ = ½ Σ|λᵢ|`（λᵢ は ρ−σ の固有値）を計算し、忠実度と並行して報告する。

### 修正2: 収束次数分析をトレース距離ベースに拡張

忠実度不忠実度とトレース距離の両方で収束次数を算出し、1−F ≈ T² 関係を検証する。

### 修正3: 古典 Trotter 参照解の追加

`build_trotter_step_classical` のアプローチ（Hamiltonian 部分は 81×81 のユニタリ、散逸子部分は expm_multiply による正確な exp(L_D·dt)）を用いて、Stinespring 近似を含まない古典的 Trotter 分割の参照解を計算する。

これにより以下の独立な誤差測定が可能：

| 比較 | 測定される誤差 |
|------|--------------|
| ST(n) vs Exact | 全体誤差（Stinespring + Trotter + 個別チャネル Trotter） |
| ClassicalTrotter(n) vs Exact | H-D Trotter 分割誤差のみ |
| ST(n) vs ClassicalTrotter(n) | Stinespring 近似 + 個別チャネル Trotter 誤差 |

**注意**: ClassicalTrotter は散逸子を一括処理 (exp(L_D·dt)) するのに対し、ST は個別チャネルを Stinespring で逐次適用するため、Trotter 分割構造が異なる。ST(n) vs ClassicalTrotter(n) は Stinespring 近似誤差と個別チャネル Trotter 誤差の合計を測定する。

### 修正4: 不正確な Stinespring 減算列の除去

`infid_stinespring = infid_total − infid_trotter` の列を除去し、上記の独立な比較に置き換える。
