## 問題1（重大）：収束次数の不一致 — 主張 O(dt²) vs 実測 O(dt)

→ ST と CT の差は O(dt) であり、ST の追加誤差が1次であることを直接確認。

### なぜ Rate(1-F) ≈ 2.0 なのにRate(T) ≈ 1.0 なのか

これは矛盾ではない。Fuchs–van de Graaf 不等式：

$$T(\rho, \sigma)^2 \leq 1 - F(\rho, \sigma) \leq 2T(\rho, \sigma)$$

混合状態では、データから `1-F ≈ c·T²` となっている（d_B/T 比 ≈ 5.4〜7.3 から確認）。したがって：
- T = O(dt) → Rate(T) ≈ 1.0
- 1-F ≈ T² = O(dt²) → Rate(1-F) ≈ 2.0

**Rate(1-F) ≈ 2.0 は真の2次収束を意味しない。** 真の状態距離メトリクスであるトレース距離は O(dt) で収束している。

### 根本原因の分析

`QuditGKSLSimulator._trotter_step` の実装：

```python
def _trotter_step(self, rho):
    """2nd-order symmetric Trotter step.                    ← ★ 不正確な記述
    exp(L dt) ~ exp(L_H dt/2) prod_alpha exp(L_D_alpha dt) exp(L_H dt/2)
    """
    rho = self._U_H_half @ rho @ self._U_H_half.conj().T    # exp(L_H dt/2)
    for U_stine in self._U_stines:                            # prod_α E_α(dt)
        rho = apply_stinespring_to_density_matrix(rho, U_stine)
    rho = self._U_H_half @ rho @ self._U_H_half.conj().T    # exp(L_H dt/2)
    return rho
```

**3段階の誤差分解：**

| 分解レベル | 近似 | ステップ局所誤差 | 大域誤差 |
|-----------|------|----------------|---------|
| (1) Strang 分割: H-D | `exp(L_H dt/2)·exp(L_D dt)·exp(L_H dt/2) = exp(L dt) + O(dt³)` | O(dt³) | **O(dt²) ← 2次** |
| (2) Lie-Trotter 積: D₁…D₂₆ | `prod_α exp(L_{D_α} dt) = exp(L_D dt) + O(dt²)` | O(dt²) | **O(dt) ← 1次** |
| (3) Stinespring 近似: E_α | `E_α(ρ) = exp(L_{D_α} dt)(ρ) + O(dt²)` | O(dt²) | **O(dt) ← 1次** |

**支配的な誤差は (2) と (3) の O(dt²)/ステップであり、大域収束は O(dt)（1次）に制限される。**

#### 誤差源 (2): Lie-Trotter 積の1次誤差

26個の Lindblad チャネルを逐次適用する際、異なるチャネルの非可換性から生じる：

$$\prod_{\alpha} e^{L_{D_\alpha} dt} = e^{L_D dt} + \frac{dt^2}{2}\sum_{\alpha < \beta}[L_{D_\alpha}, L_{D_\beta}] + O(dt^3)$$

#### 誤差源 (3): Stinespring 拡張の1次近似

各 Stinespring チャネルは2準位アンシラを使用：

$$U = \exp\left(-i\sqrt{dt}\begin{pmatrix}0 & L^\dagger \\ L & 0\end{pmatrix}\right)$$

部分トレースにより：

$$E_\alpha(\rho) = \rho + dt \cdot \mathcal{D}[L_\alpha](\rho) + O(dt^2)$$

ここで $\mathcal{D}[L](\rho) = L\rho L^\dagger - \{L^\dagger L, \rho\}/2$ が Lindblad 散逸子。O(dt²) の補正項は $\frac{dt^2}{4}L^\dagger L \rho L^\dagger L$ 等の項を含む。

**2準位アンシラの Stinespring 拡張は、有限 dt に対して正確な Lindblad チャネル `exp(L_{D_α} dt)` を再現できない**（正確な再現には無限個の Kraus 演算子が必要だが、2準位アンシラは2個しか提供できない）。

### 対比：Classical Trotter (CT) が2次な理由

CT シミュレータ (`_classical_trotter_simulate`) の実装：

```python
rho = U_H_half @ rho @ U_H_half_dag          # exp(L_H dt/2)  - Hilbert空間ユニタリ
vec = expm_multiply(L_D_super * dt, vec)       # exp(L_D dt)    - 合計散逸子の正確な指数
rho = U_H_half @ rho @ U_H_half_dag          # exp(L_H dt/2)  - Hilbert空間ユニタリ
```

- 合計散逸子 `L_D = Σ_α L_{D_α}` を**単一の行列指数**として適用 → 積公式誤差なし
- Stinespring 近似なし（超演算子空間で正確に計算）
- 唯一の誤差源は Strang 分割のみ → O(dt³)/ステップ → **O(dt²) 大域（2次）**

## 修正方針

### 1. ドキュメントの修正

`qudit_gksl_simulator.py` および `qubit_gksl_simulator.py` のドキュメント文字列を修正し、実効収束次数を正確に記述する：

- 「2nd-order symmetric Trotter step」→ Hamiltonian-散逸子の Strang 分割は2次だが、Stinespring 近似と Lindblad チャネルの逐次適用により実効収束は O(dt)（1次）であることを明記

### 2. 対称（回文順）Lindblad 積の実装

Lie-Trotter 積の誤差（源 (2)）を除去するため、Lindblad チャネルの適用順序を対称化する：

**現在の実装（1次積）:**
```
E_1(dt) · E_2(dt) · ... · E_26(dt)
```

**対称化後（2次積）:**
```
E_1(dt/2) · E_2(dt/2) · ... · E_26(dt/2) · E_26(dt/2) · ... · E_2(dt/2) · E_1(dt/2)
```

これにより：
- 誤差源 (2) は O(dt²)/ステップ → O(dt³)/ステップに改善
- 誤差源 (3) は O(dt²)/ステップのまま（ただし係数は ~1/2 に改善）
- **実効収束次数は依然 O(dt)（1次）だが、定数係数が改善される**

**注意**: これはごまかしではなく、数学的に正当な改善。Lie-Trotter 積の交換子誤差を除去する標準的手法。

### 3. 誤差分解のための診断出力

Iteration 21 検証スクリプトに「Classical Product Trotter」比較を追加：
- **Classical Product Trotter**: `exp(L_H dt/2) · prod_α exp(L_{D_α} dt) · exp(L_H dt/2)`
  - 超演算子空間で個別チャネルの正確な指数を適用（Stinespring なし）
  - Lie-Trotter 積誤差のみを含む

これにより以下の分離が可能：
- ST vs Classical Product = **Stinespring 近似誤差のみ**
- Classical Product vs CT = **Lie-Trotter 積誤差のみ**
- ST vs CT = **両方の合計**

### 4. 真の2次収束の達成について

真の2次収束を達成するには、Stinespring 拡張自体を2次精度に改善する必要がある。これには：
- 3準位以上のアンシラを使用して追加の Kraus 演算子を得る
- または修正されたジェネレータ G' = [[A, L†], [L, B]]（A, B ≠ 0）を使用する

これは研究レベルの課題であり、本 iteration では対象外とする。
