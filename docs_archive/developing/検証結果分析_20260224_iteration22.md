## 問題1（重大）：CPT比較が誤差を正しく分離できていない

### 症状

Iteration 21 の誤差分解は以下の対応を主張している：

| 比較ペア | 主張される分離誤差 |
|----------|------------------|
| ST vs CPT | Stinespring 近似誤差のみ |
| CPT vs CT | Lie-Trotter 積公式誤差のみ |

しかし、数値データはこの主張と矛盾している。

### 数値的証拠

dt=0.2 における各比較ペアのトレース距離：

| 比較ペア | T(ρ,σ) | 主張される意味 |
|----------|---------|---------------|
| T(ST, CT) | 3.9700e-05 | 「Stinespring + Lie-Trotter 積誤差」 |
| T(ST, CPT) | 1.6545e-04 | 「Stinespring 近似誤差のみ」 |
| T(CPT, CT) | 1.2909e-04 | 「Lie-Trotter 積公式誤差のみ」 |

**矛盾点**: T(ST, CPT) = 1.6545e-04 が「Stinespring 誤差のみ」であるなら、T(ST, CT) ≈ T(ST, CPT) + T(CPT, CT) ≈ 2.9454e-04 のはずだが、実際は T(ST, CT) = 3.97e-05 しかない。T(ST, CT) << T(ST, CPT) である。

つまり、**ST は CPT よりも CT に4倍以上近い**。「Stinespring 近似誤差のみ」がこれほど大きいのに、「Stinespring + Lie-Trotter 積誤差」がその1/4になるのは論理的に不可能である。

### 根本原因

ST と CPT では **Lindblad チャネルの適用順序が異なる**：

| シミュレータ | チャネル適用構造 | 時間刻み |
|------------|----------------|---------|
| **ST** | 回文順（palindromic）: `E_1(dt/2)...E_26(dt/2) · E_26(dt/2)...E_1(dt/2)` | dt/2 × 2回 |
| **CPT** | 順方向のみ（forward-only）: `exp(L_{D_1} dt)...exp(L_{D_26} dt)` | dt × 1回 |

ST vs CPT の差には以下の **2つの独立した誤差源** が混在している：

1. **Stinespring 近似誤差**: E_α(dt/2) vs exp(L_{D_α} dt/2)
2. **順序の差**: 回文順（2次精度）vs 順方向のみ（1次精度）

CPT の順方向 Lie-Trotter 積誤差は O(dt²)/ステップ → O(dt) 大域であり、これは ST が回文順で除去した誤差と同じ性質のものである。ST vs CPT はこの除去された誤差と Stinespring 誤差の差を見ており、純粋な Stinespring 誤差を分離できていない。

### 正しい誤差分離方法

Stinespring 誤差を正しく分離するには、**ST と同じ回文順構造を持つ古典的参照** が必要：

**対称古典積 Trotter（SCPT: Symmetric Classical Product Trotter）**
```
exp(L_H dt/2) · [prod_{α=1..26} exp(L_{D_α} dt/2)] · [prod_{α=26..1} exp(L_{D_α} dt/2)] · exp(L_H dt/2)
```

SCPT は ST と同一の構造を持つが、Stinespring 近似の代わりに正確なチャネル指数関数を使用する。したがって：

| 比較ペア | 分離される誤差 |
|----------|--------------|
| **ST vs SCPT** | **純粋な Stinespring 近似誤差** |
| SCPT vs CT | 回文順 Lie-Trotter 残差 + Strang 差（O(dt²)） |
| CPT vs CT | 順方向 Lie-Trotter 積誤差（O(dt)） |
| ST vs CT | Stinespring 誤差 + 高次残差 ≈ Stinespring 誤差（小さい dt で） |

### 補足：T(ST, CT) は小さい dt で Stinespring 誤差の良い近似

ST の回文順により Lie-Trotter 積誤差は O(dt³)/ステップ（O(dt²) 大域）に抑制されている。CT は Strang 分割誤差のみ（O(dt²) 大域）。したがって：

```
T(ST, CT) = ||err_Stinespring + err_palindromic_residual - err_Strang|| / 2
```

小さい dt では err_Stinespring（O(dt)）が支配的であり、O(dt²) 項は無視できるため：

```
T(ST, CT) ≈ Stinespring 誤差（小さい dt）
```

数値的にも Rate(T) for ST vs CT ≈ 1.00 であり、O(dt) 収束を確認している。

## 問題2（中程度）：収束次数の報告が誤解を招く

### 症状

ST vs Exact の Rate(T) が大幅に変動している：

| dt 範囲 | Rate(T) |
|---------|---------|
| 2.0 → 1.0 | 2.05 |
| 1.0 → 0.5 | 1.82 |
| 0.5 → 0.2 | **0.91** |
| **平均** | **1.59** |

平均 1.59 は O(dt) でも O(dt²) でもなく、物理的に意味のある収束次数を表していない。

### 根本原因：誤差レジームの遷移

ST vs Exact の全誤差は複数の項からなる：

```
T(ST, exact) = ||C_S · dt + C_Strang · dt² + 高次項|| × (t_max / dt)^k
```

ここで C_S は Stinespring 誤差の係数、C_Strang は Strang 分割誤差の係数。

- **大きい dt（dt ≈ 2.0）**: C_Strang · dt² が相対的に大きい → 見かけの Rate ≈ 2
- **小さい dt（dt ≈ 0.2）**: C_S · dt が支配的 → 見かけの Rate → 1
- **遷移領域（dt ≈ 0.5）**: 両方の項が同程度 → Rate は中間値

### 追加的複雑さ：誤差相殺

Stinespring 誤差と Strang 分割誤差は密度行列空間で部分的に逆方向を向いており、相殺が生じている：

| dt | T(ST,ex) | T(ST,CT)+T(CT,ex) | 相殺比 |
|----|---------|-------------------|-------|
| 2.00 | 1.103e-03 | 1.635e-03 | 0.675 |
| 1.00 | 2.670e-04 | 5.056e-04 | 0.528 |
| 0.50 | 7.586e-05 | 1.759e-04 | 0.431 |
| 0.20 | 3.303e-05 | 5.195e-05 | 0.636 |

三角不等式 T(A,C) ≤ T(A,B) + T(B,C) の等号からの乖離は 0.43〜0.68 であり、誤差ベクトルの方向が概ね逆向きであることを示す。

dt=0.5 で相殺比が最小（0.431）となるのは、この近傍で Stinespring 誤差と Strang 誤差の大きさが同程度かつ方向が最も逆向きになるためと考えられる。

この誤差相殺は系パラメータと初期状態に依存する偶然的効果であり、精度保証の根拠にはできない。

### 推奨される報告方法

1. **漸近的収束次数**（dt→0 での Rate）を主要指標とする
2. 遷移領域の Rate 変動は多項式フィッティング `T ≈ a·dt + b·dt²` で説明する
3. 「平均 Rate」は廃止し、代わりに最小 dt での Rate を報告する

## 問題3（軽微）：N_S1 収束の非単調性

### 症状

| n_steps | dt | |Δ_ST| | 符号付きΔ_ST |
|---------|-----|-------|------------|
| 20 | 0.50 | 1.2048e-05 | −1.2048e-05（過少） |
| 50 | 0.20 | 1.3045e-05 | +1.3045e-05（過大） |

絶対誤差がわずかに増加している。

### 原因

N_S1 誤差の符号が dt ≈ 0.45 付近で反転している。これは Stinespring 誤差によるN_S1 方向の誤差成分が正から負に（またはその逆に）遷移するためであり、バグではない。

全密度行列のトレース距離は単調減少している：
- dt=0.50: T(ST, exact) = 7.586e-05
- dt=0.20: T(ST, exact) = 3.303e-05

N_S1 はスカラー射影であり、密度行列の全情報のうち1次元方向の成分しか反映しない。符号付き誤差がゼロを横切る dt が存在するのは数学的に自然である。

### 推奨

- N_S1 の収束分析では符号付き誤差 Δ_ST（絶対値ではなく）を報告する
- 全密度行列の距離指標（トレース距離）を主要指標とする（現在もそうなっている）

## ノイズ付きシミュレータに関する注意

`QuditGKSLNoisySimulator` および `QubitGKSLNoisySimulator` は `_trotter_step` をオーバーライドし、**順方向のみ**（回文順ではない）で `self._U_stines`（full-dt）を使用している。これは：

1. ノイズは各ゲート直後に適用する必要があり、回文順との組み合わせが複雑

したがって、これは設計上の意図的な選択であり、問題ではない。

## 修正方針（Iteration 22）

### 1. 対称古典積 Trotter（SCPT）の追加

新しい参照シミュレータとして SCPT を検証スクリプトに追加：

```python
def _symmetric_classical_product_trotter_simulate(
    H_total, L_D_individual, rho_0, t_max, n_steps, dim):
    """回文順の個別散逸子指数関数を使用（ST と同じ順序構造）"""
    dt = t_max / n_steps
    U_H_half = expm(-1j * H_total * dt / 2)
    for _ in range(n_steps):
        rho = U_H_half @ rho @ U_H_half†
        # 順方向 dt/2
        for L_D_alpha in L_D_individual:
            vec = expm_multiply(L_D_alpha * (dt/2), vec)
        # 逆方向 dt/2（回文順）
        for L_D_alpha in reversed(L_D_individual):
            vec = expm_multiply(L_D_alpha * (dt/2), vec)
        rho = U_H_half @ rho @ U_H_half†
    return rho
```

### 2. 拡張された比較ペア

| 比較ペア | 分離される誤差 | 期待される収束次数 |
|----------|--------------|-----------------|
| ST vs Exact | 全誤差 | O(dt)（漸近的） |
| CT vs Exact | Strang H-D 分割 | O(dt²) |
| CPT vs Exact | 順方向 Lie-Trotter + Strang | O(dt) |
| **SCPT vs Exact** | **回文順 Lie-Trotter 残差 + Strang** | **O(dt²)** |
| **ST vs SCPT** | **純粋 Stinespring 近似誤差** | **O(dt)** |
| SCPT vs CT | 回文順 Lie-Trotter 残差 | O(dt²) |
| CPT vs CT | 順方向 Lie-Trotter 積誤差 | O(dt) |
| ST vs CT | Stinespring 誤差（近似） | O(dt) |

### 3. 改善された報告

- 符号付き N_S1 誤差の追加
- 漸近 Rate（最小 dt）と遷移 Rate の分離
- 誤差相殺分析（三角不等式の余裕度）
- 多項式フィッティング `T ≈ a·dt + b·dt²` の係数推定
