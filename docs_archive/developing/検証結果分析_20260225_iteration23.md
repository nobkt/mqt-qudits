## 問題1（中程度）：多項式フィッティング T(ST,exact) ≈ a·dt + b·dt² の根本的不適切性

### 症状

Iteration 22 の多項式フィッティング結果：

| dt | T(ST,exact) 実測値 | フィット値 | 相対誤差 |
|----|-------------------|-----------|---------|
| 2.00 | 1.1029e-03 | 1.0599e-03 | **3.8%** |
| 1.00 | 2.6698e-04 | 3.0103e-04 | **12.8%** |
| 0.50 | 7.5858e-05 | 9.3121e-05 | **22.8%** |
| 0.20 | 3.3027e-05 | 2.3523e-05 | **28.9%** |

フィット係数：a = 7.152e-05, b = 2.295e-04

最大相対誤差 29% は分析としては不適切であり、この係数を誤差の物理的源泉と解釈することは誤りを招く。

### 根本原因：誤差相殺による非加法性

T(ST,exact) は Stinespring 誤差と Strang 分割誤差の**ベクトル和**であり、これらの誤差は密度行列空間で部分的に逆方向を向くため、単純なスカラー加算 `a·dt + b·dt²` は成り立たない。

SCPT を用いた三角不等式の検証：

| dt | T(ST,ex) 実測 | T(ST,SCPT) + T(SCPT,ex) | 相殺比 |
|----|-------------|------------------------|-------|
| 2.00 | 1.1029e-03 | 1.6379e-03 | 0.673 |
| 1.00 | 2.6698e-04 | 5.0637e-04 | 0.527 |
| 0.50 | 7.5858e-05 | 1.7607e-04 | **0.431** |
| 0.20 | 3.3027e-05 | 5.1976e-05 | 0.635 |

相殺比が 0.43〜0.67 の範囲で変動し、dt=0.5 で最小（最大相殺）。この非単調な相殺パターンは `a·dt + b·dt²` モデルでは捉えられない。

### 正しい誤差解析方法

**各成分を個別にフィッティングする**ことで、極めて高精度なフィットが得られる：

#### Stinespring 誤差（T(ST,SCPT) = a_stine · dt）

| dt | T(ST,SCPT) 実測 | a_stine · dt | 相対誤差 |
|----|----------------|-------------|---------|
| 2.00 | 3.9603e-04 | 3.9687e-04 | **0.21%** |
| 1.00 | 1.9861e-04 | 1.9843e-04 | **0.09%** |
| 0.50 | 9.9302e-05 | 9.9217e-05 | **0.09%** |
| 0.20 | 3.9700e-05 | 3.9687e-05 | **0.03%** |

**a_stine = 1.984e-04**（最大相対誤差 0.21%、元のフィットの a = 7.15e-05 とは**2.77倍**の乖離）

#### Strang/回文順残差（T(SCPT,exact) = b_strang · dt²）

| dt | T(SCPT,ex) 実測 | b_strang · dt² | 相対誤差 |
|----|----------------|---------------|---------|
| 2.00 | 1.2419e-03 | 1.2322e-03 | **0.78%** |
| 1.00 | 3.0775e-04 | 3.0805e-04 | **0.10%** |
| 0.50 | 7.6771e-05 | 7.7012e-05 | **0.31%** |
| 0.20 | 1.2276e-05 | 1.2322e-05 | **0.38%** |

**b_strang = 3.080e-04**（最大相対誤差 0.78%、元のフィットの b = 2.30e-04 とは**1.34倍**の乖離）

### 結論

元の多項式フィッティングは**定量的に不正確**であり、フィット係数を「Stinespring 誤差係数」「Strang 誤差係数」と解釈することは誤りである。成分別フィッティングにより正確な誤差係数が得られ、相対誤差は 1% 未満に改善される。

### 修正方針

- T(ST,SCPT) と T(SCPT,ex) を個別にフィッティング
- 正規化係数 T(ST,SCPT)/dt と T(SCPT,ex)/dt² の直接表示
- 元の T(ST,ex) のフィッティングは参考値として残すが、主要指標としない

## 問題2（中程度）：SCPT 基準の相殺比分析の欠如

### 症状

Iteration 22 の相殺比は CT 基準で定義されている：

```
cancel_CT = T(ST,exact) / (T(ST,CT) + T(CT,exact))
```

しかし、SCPT が導入された今、より原理的な SCPT 基準の相殺比を計算すべきである：

```
cancel_SCPT = T(ST,exact) / (T(ST,SCPT) + T(SCPT,exact))
```

### 理由

SCPT 基準の方が物理的に意味のある分解を与える：

- T(ST,SCPT) = 純粋な Stinespring 近似誤差（O(dt)）
- T(SCPT,exact) = Strang 分割 + 回文順残差（O(dt²)）

これらは**独立な物理的誤差源**であり、相殺比は「これらの誤差ベクトルの方向関係」を定量化する。

### 数値的検証

CT 基準と SCPT 基準の相殺比は実質的に同一値を与える（T(ST,SCPT) ≈ T(ST,CT) かつ T(SCPT,ex) ≈ T(CT,ex) のため）：

| dt | cancel_CT | cancel_SCPT | 差 |
|----|----------|------------|-----|
| 2.00 | 0.675 | 0.673 | 0.002 |
| 1.00 | 0.528 | 0.527 | 0.001 |
| 0.50 | 0.431 | 0.431 | 0.000 |
| 0.20 | 0.636 | 0.635 | 0.001 |

差は微小であるが、SCPT 基準の方が概念的に明確である。

### 修正方針

- SCPT 基準の相殺比を追加計算
- 両方の相殺比を出力し、一致を確認

## 正常な結果の確認

### 全収束次数の理論的整合性 ✅

| 比較ペア | 理論予測 Rate(T) | 実測 Rate(T) | 整合性 |
|----------|-----------------|-------------|--------|
| ST vs SCPT | O(dt) → Rate 1 | 1.00, 1.00, 1.00 | ✅ 完全 |
| ST vs CT | O(dt) → Rate 1 | 1.00, 1.00, 1.00 | ✅ 完全 |
| CT vs Exact | O(dt²) → Rate 2 | 2.01, 2.00, 2.00 | ✅ 完全 |
| SCPT vs Exact | O(dt²) → Rate 2 | 2.01, 2.00, 2.00 | ✅ 完全 |
| SCPT vs CT | O(dt²) → Rate 2 | 1.98, 2.00, 2.00 | ✅ 完全 |
| CPT vs CT | O(dt) → Rate 1 | 0.97, 0.99, 1.00 | ✅ 漸近 |
| ST vs Exact | O(dt) 漸近 | 2.05, 1.82, 0.91 | ⚠️ 混合（下記参照） |
| CPT vs Exact | O(dt) 漸近 | 1.40, 1.24, 1.12 | ⚠️ 混合（下記参照） |

### ST vs Exact の Rate 変動について

Rate(T) = 2.05 → 1.82 → 0.91 の変動は**バグではなく物理的に正当**：

1. **大きい dt**: O(dt²) の Strang 成分が支配 → 見かけの Rate ≈ 2
2. **小さい dt**: O(dt) の Stinespring 成分が支配 → 見かけの Rate → 1
3. **遷移領域**: 両方の成分が同程度 → Rate は中間値

dt=0.5→0.2 で Rate = 0.91 < 1.0 になるのは、相殺の非単調性による：dt=0.5 で強い相殺（cancel=0.43）が dt=0.2 で弱まる（cancel=0.64）ため、T(ST,ex) の減少率が Stinespring 誤差単体の減少率 O(dt) より小さくなる。

### T(ST,SCPT) ≈ T(ST,CT) の意味 ✅

全 dt 値で T(ST,SCPT) ≈ T(ST,CT) であることは、SCPT ≈ CT（回文順残差が無視可能）であることを意味する。これは：

1. Iteration 21 の「ST vs CT が小さい dt で Stinespring 誤差の良い近似」という主張を定量的に確認
2. SCPT は CT の正しさを独立に検証する役割を果たした
3. SCPT と CT の差 T(SCPT,CT) は Stinespring 誤差の 1/200 未満
