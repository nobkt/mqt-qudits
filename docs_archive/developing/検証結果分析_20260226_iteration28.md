## 問題点1：HO 合成モデルが小さい dt で単純モデルより悪化

### 症状

| dt | 単純モデル誤差 | HO モデル誤差(cos_mean) | HO の方が良い？ |
|----|-------------|---------------------|---------------|
| 2.00 | **1.1263%** | **0.2343%** | ✅ 4.8x 改善 |
| 1.00 | 0.0186% | 0.1586% | ❌ 8.5x 悪化 |
| 0.50 | 0.0657% | 0.0543% | ✅ 1.2x 改善 |
| 0.20 | 0.0238% | 0.0803% | ❌ 3.4x 悪化 |
| 0.10 | 0.0060% | 0.0993% | ❌ 16.5x 悪化 |

HO モデルの最大誤差は 0.23%（単純の 1.13% から改善）だが、dt ≤ 1.0 では 3/4 の dt 値で単純モデルが優位。

### 根本原因

単純モデルは `a_F = mean(d_F(ST,SCPT)/dt)` を使用。この平均値はたまたま小さい dt の値に近い（d_F(ST,SCPT)/dt の変動は 0.28% と小さく、平均が漸近値に近い）ため、小さい dt での合成モデル誤差が偶然的に非常に小さくなる。

一方 HO モデルは最小二乗法で 2 パラメータ（a_F0 + a_F1·dt）をフィッティングするため、各 dt での個別フィット精度は平均に劣る（max 0.11% vs 0.08%）。この差が非線形な合成モデルを通じて増幅される。

### 重要な補足

単純モデルの小さい dt での優位性は **偶然的な誤差相殺** に依存している。HO モデルはより系統的な近似であり、全体的な max error は改善されている。ただし、モデルの目的が「全 dt で均一に良い精度」であるなら、cos(θ_F) の dt 依存性のモデリングが必要。

## 問題点2：cos(θ_F) が定数（平均値）として扱われている

### 症状

cos(θ_F) の dt 依存性：

| dt | cos(θ_F) 実測 | cos_mean | 差異 |
|----|-------------|----------|------|
| 2.00 | -0.5730 | -0.5757 | +0.0027 |
| 1.00 | -0.5758 | -0.5757 | -0.0001 |
| 0.50 | -0.5765 | -0.5757 | -0.0008 |
| 0.20 | -0.5767 | -0.5757 | -0.0010 |
| 0.10 | -0.5767 | -0.5757 | -0.0010 |

cos(θ_F) は dt→0 で -0.5767 に収束し、大きい dt では -0.5730 に向かう。変動幅は 0.64% と小さいが、定数近似は系統的誤差を導入する。

### cos(θ_F) の dt² モデリング

cos(θ_F)(dt) = c₀ + c₁·dt² の最小二乗フィット：
- c₀ = -0.5767194583
- c₁ = +0.0009175447
- フィット最大誤差: 9.12e-06（cos の変動範囲 0.0037 の 0.25%）

比較: cos(θ_F)(dt) = c₀ + c₁·dt の場合：
- フィット最大誤差: 5.30e-04（dt² モデルの 58 倍悪い）

**dt² モデルが物理的に正当化される理由**：
- δ_stine の主項は O(dt)、補正は O(dt²)
- δ_strang の主項は O(dt²)、補正は O(dt³)
- 誤差ベクトル間の角度の主補正は O(dt²) になる

### cos(θ_F) モデリングの合成モデルへの効果

| dt | HO(cos_mean)% | HO(cos_dt²)% | 改善 |
|----|-------------|-------------|------|
| 2.00 | 0.2343% | 0.1140% | 2.1x |
| 1.00 | 0.1586% | 0.1532% | 1.0x |
| 0.50 | 0.0543% | 0.0259% | 2.1x |
| 0.20 | 0.0803% | 0.0423% | 1.9x |
| 0.10 | 0.0993% | 0.0821% | 1.2x |

cos(θ_F) の dt² モデリングにより、最大誤差が 0.23% → 0.15% に改善（1.5x）。

## 問題点3：合成モデル誤差の分解診断が欠如

### 症状

合成モデル誤差が単一の値として報告されているが、誤差源の分解がない。2 つの独立な誤差源の寄与が不明：
1. 係数フィッティング誤差（a_F(dt), b_F(dt) のモデル vs 実測の差）
2. cos(θ_F) 近似誤差（cos_mean vs per-dt cos の差）

### 誤差分解結果（独自分析）

| dt | 係数誤差のみ(%) | cos 誤差のみ(%) | 複合誤差(%) |
|----|---------------|---------------|-----------|
| 2.00 | 0.1139% | 0.1203% | 0.2343% |
| 1.00 | 0.1523% | 0.0063% | 0.1586% |
| 0.50 | 0.0259% | 0.0802% | 0.0543% |
| 0.20 | 0.0424% | 0.0379% | 0.0803% |
| 0.10 | 0.0822% | 0.0171% | 0.0993% |

**注**: 複合誤差は係数誤差と cos 誤差の単純和ではない（非線形相互作用があるため、一部は相殺、一部は増幅）。

### 重要な洞察

1. **dt=2.0**: 係数誤差(0.11%)と cos 誤差(0.12%)がほぼ等分 → 両方の改善が必要
2. **dt=1.0**: 係数誤差(0.15%)が支配的 → cos 改善の効果小
3. **dt=0.5**: 非線形相殺により複合誤差(0.05%)が個別誤差より小さい
4. **dt=0.1**: 係数誤差(0.08%)が支配的

全体として、**係数フィッティング誤差が主要な残存誤差源**。cos(θ_F) モデリングは dt=2.0 で最も効果的だが、小さい dt では限界あり。

## 問題点4（構造的制約）：5 データ点での 2 パラメータフィットの限界

### 症状

HO フィッティング（a_F0 + a_F1·dt）は 5 データ点で 2 パラメータをフィットしているため、自由度は 3。このフィットの残差は「真の」高次補正（a_F2·dt² 等）とノイズの混合を反映している。

### 含意

- 3 パラメータフィット（a_F0 + a_F1·dt + a_F2·dt²）は自由度 2 で可能だが、過剰適合のリスクあり
- 現状の 2 パラメータモデルが最適なバランスである可能性が高い
- **これ以上の係数精度向上には、追加の dt 値でのシミュレーションが必要**
