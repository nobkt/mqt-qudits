## 発見された問題: Strang 係数モデル形式の理論的誤り

### 問題の核心

現行 HO モデルでは、Strang 係数を以下でフィッティングしている:

```
d_F(SCPT,ex) / dt² = b_F0 + b_F1·dt     （dt 線形補正）
```

しかし、Strang 分割（対称分割）の誤差構造から、正しいモデル形式は:

```
d_F(SCPT,ex) / dt² = b_F0 + b_F2·dt²    （dt² 偶数次補正）
```

### 理論的根拠

Strang（対称）分割 exp(L_H dt/2) · exp(L_D dt) · exp(L_H dt/2) は、対称性から奇数次の誤差項が消滅する。したがって:

```
d_F(SCPT,ex) = b_F0·dt² + b_F2·dt⁴ + b_F4·dt⁶ + ...   （偶数次のみ）
```

正規化すると:
```
d_F(SCPT,ex)/dt² = b_F0 + b_F2·dt² + b_F4·dt⁴ + ...    （偶数次補正のみ）
```

dt 線形項（b_F1·dt）は Strang 分割の対称性により存在しないはずである。

## 補足分析: Stinespring 係数モデル

### Stinespring 係数の dt 依存性

d_F(ST,SCPT)/dt の実測値:

| dt | d_F(ST,SCPT)/dt |
|----|----------------|
| 2.00 | 2.2228e-04 |

| 0.20 | 2.2276e-04 |
| 0.10 | 2.2270e-04 |

→ **非単調パターン**: dt=1.0 でピーク、dt→0 と dt→2 の両方で減少。

### Stinespring モデル比較

| モデル | パラメータ数 | 成分最大誤差 |
|--------|-----------|-----------|
| a_F0 + a_F1·dt（現行）| 2 | 0.113% |
| a_F0 + a_F2·dt²（代替）| 2 | 0.085% |
| a_F0 + a_F1·dt + a_F2·dt²（拡張）| 3 | 0.0005% |

dt² モデルは dt モデルより 1.3x 良いが、Strang ほどの劇的差ではない。
これは Stinespring 誤差が対称分割ではないため、奇数次補正 (a_F1·dt) が存在するためである。

3 パラメータモデル（a_F0 + a_F1·dt + a_F2·dt²）は非常に高精度だが、
5 データ点で 3 パラメータ（自由度 2）のため、過剰適合リスクあり。

### Stinespring の推奨

Stinespring には以下の 2 つの選択肢がある:
1. **a_F0 + a_F1·dt**: 理論的に正しい形式（奇数次が存在）、最大誤差 0.113%
2. **a_F0 + a_F2·dt²**: 数値的にはわずかに良い（0.085%）が、理論的には奇数次の省略

Iteration 29 では両方を検証し、合成モデル精度で比較する:
- Stine-dt + Strang-dt²: 最大 0.074%
- Stine-dt² + Strang-dt²: 最大 0.065%

差は小さいため、実用上は Stine-dt（理論的正当性）を推奨、Stine-dt² は参照として出力。
