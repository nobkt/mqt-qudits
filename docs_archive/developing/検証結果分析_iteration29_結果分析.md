## 発見された問題: Stinespring 係数モデルの限界

### 問題の核心

M5 の残存誤差パターンは異常である:

| dt | M5 誤差% | 支配的誤差源 |
|----|---------|-----------|
| 2.00 | 0.0078 | Stinespring |
| 1.00 | 0.0056 | Stinespring |
| 0.50 | **0.0413** | **Stinespring** |
| 0.20 | **0.0367** | **Stinespring** |
| 0.10 | **0.0741** | **Stinespring** |

**小さい dt で誤差が増大**するという反直感的パターンは、Stinespring 成分が全誤差に占める割合が dt → 0 で増大することに起因する。

### 詳細分析: 各成分の支配度

| dt | Stine/Total 比 | Strang/Total 比 | Stine 誤差のみ% | Strang 誤差のみ% | cos 誤差のみ% |
|----|---------------|----------------|---------------|----------------|-------------|
| 2.00 | 0.381 | 1.168 | 0.0069 | 0.0008 | 0.0001 |
| 1.00 | 0.803 | 1.217 | 0.0093 | 0.0028 | 0.0009 |
| 0.50 | **1.195** | 0.903 | **0.0413** | 0.0000 | 0.0001 |
| 0.20 | **1.160** | 0.351 | **0.0367** | 0.0001 | 0.0001 |
| 0.10 | **1.086** | 0.164 | **0.0741** | 0.0001 | 0.0001 |

dt ≤ 0.5 では Stinespring 成分が Total を超え（クロスオーバー領域）、Stinespring 係数の精度が合成モデル精度を完全に支配する。

### 根本原因: a_F(dt) の非単調性

d_F(ST,SCPT)/dt の実測値は**非単調**（dt ≈ 1.0 で極大）:

| dt | a_F(dt) = d_F(ST,SCPT)/dt |
|----|--------------------------|
| 2.00 | 2.22278e-04 |
| 1.00 | **2.22900e-04** (極大) |
| 0.50 | 2.22876e-04 |
| 0.20 | 2.22757e-04 |
| 0.10 | 2.22700e-04 |

変動幅: 0.279%（小さいが無視できない）

線形モデル a_F0 + a_F1·dt は単調関数であり、この非単調パターンを捕捉できない。

### 物理的解釈

Stinespring ユニタリ U = exp(-i·√dt·G) による誤差の Taylor 展開:

```
d_F(ST,SCPT) = a_F0·dt + a_F1·dt² + a_F2·dt³ + ...
```

正規化すると:
```
a_F(dt) = d_F(ST,SCPT)/dt = a_F0 + a_F1·dt + a_F2·dt² + ...
```

- a_F0: 漸近 Stinespring 誤差係数（正）
- a_F1: 1次補正（正、higher-order Stinespring 項から）
- a_F2: 2次補正（負、exact ユニタリの精度回復効果）

a_F1 > 0, a_F2 < 0 のとき、極大は dt = -a_F1/(2·a_F2) に現れる。
