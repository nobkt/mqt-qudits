## 1. 概要

本報告書は`tutorials/quantum_dynamics_complete_comparison.ipynb`で実施されている4分子TTA-UCシミュレーションの理論・仕様・設計を整理し、発見されたバグの詳細分析と修正内容を記述する。

### 1.1 シミュレーション対象
- **系**: 4分子線型鎖系（分子0-1-2-3）
- **状態空間**: 各分子は3準位系（|S0⟩, |T1⟩, |S1⟩）
- **物理パラメータ**: E_T=1.5 eV, E_S=3.0 eV, V=0.1 eV, J=0.05 eV, ℏ=0.6582119569 eV·fs
- **初期状態**: edge_triplet（分子0と分子3が|T1⟩、分子1と分子2が|S0⟩）
- **シミュレーション条件**: T_total=100 fs, N_steps=20, dt=5 fs

### 1.2 比較対象の4つのシミュレータ
1. **古典シミュレータ**: scipy.linalg.expmによる厳密Trotter分解
2. **Qubitシミュレータ（ノイズなし）**: Qiskit UnitaryGate/基本ゲート分解
3. **Qubitシミュレータ（ノイズあり）**: Qiskit AerSimulatorによるノイズモデル
4. **Quditシミュレータ（ノイズなし/あり）**: MQT-Quditsによるqutrit実装

## 2. 理論的基盤

### 2.1 全ハミルトニアン

$$H = H_0 + H_{transfer} + H_{TTA}$$

#### 2.1.1 対角ハミルトニアン H₀
$$H_0 = \sum_{i=0}^{3} \left( E_T |T_1\rangle_i \langle T_1|_i + E_S |S_1\rangle_i \langle S_1|_i \right)$$

単一分子の時間発展演算子:
$$U_{H_0}^{(i)}(dt) = e^{-iH_0^{(i)} dt/\hbar} = \text{diag}(1, e^{-iE_T dt/\hbar}, e^{-iE_S dt/\hbar})$$

#### 2.1.2 エネルギー移動ハミルトニアン H_transfer
隣接ペア(i,j)間の励起エネルギー移動:
$$H_{transfer}^{(i,j)} = V \left( |S_0\rangle_i|T_1\rangle_j \langle T_1|_i\langle S_0|_j + \text{h.c.} \right)$$

Qutrit (3準位) 表現: 2次元部分空間 {|01⟩, |10⟩} で回転
Qubit (2×2qubit) 表現: 4-qubit空間で {|0001⟩, |0100⟩} の2×2回転

#### 2.1.3 TTA相互作用ハミルトニアン H_TTA
$$H_{TTA}^{(i,j)} = J \left( |S_0\rangle_i|S_1\rangle_j\langle T_1|_i\langle T_1|_j + |S_1\rangle_i|S_0\rangle_j\langle T_1|_i\langle T_1|_j + \text{h.c.} \right)$$

3次元部分空間 {|02⟩, |11⟩, |20⟩} での結合:
$$H_{TTA}^{sub} = J \begin{pmatrix} 0 & 1 & 0 \\ 1 & 0 & 1 \\ 0 & 1 & 0 \end{pmatrix}$$

### 2.2 2次対称鈴木-Trotter分解
$$U(\Delta t) \approx U_{H_0}(\Delta t/2) \cdot U_{tr}(\Delta t/2) \cdot U_{TTA}(\Delta t/2) \cdot U_{TTA}(\Delta t/2) \cdot U_{tr}(\Delta t/2) \cdot U_{H_0}(\Delta t/2)$$

ただし各演算子はper-pair（ペアごと）およびper-molecule（分子ごと）に適用される。

## 3. 発見されたバグの詳細分析

### 3.1 バグ1: Qubit H₀パウリ分解の符号誤り

#### 3.1.1 問題の所在
以下のファイルに存在した符号誤り:
- `tutorials/qubit_unitary_simulator.py` (line 64-66)
- `tutorials/qubit_noisy_simulator.py` (line 120-122)
- `tutorials/exact_qubit_simulator.py` (line 110-112)
- `tutorials/standalone_qubit_exact.py` (line 51-53)
- `tutorials/test_qubit_exact_statevector.py` (line 47-49)
- `tutorials/quantum_dynamics_complete_comparison.py` (line 735-737)
- `tutorials/quantum_dynamics_complete_comparison.ipynb` (Cell 8)

#### 3.1.2 誤りの数学的分析

Qubit符号化では各分子に2 qubitを使用: |S0⟩=|00⟩, |T1⟩=|01⟩, |S1⟩=|10⟩, |11⟩は非物理状態。

H₀のパウリ分解:
$$H_0 = \alpha I \otimes I + \beta Z_0 + \gamma Z_1 + \delta Z_0 Z_1$$

ここで (d=0, 非物理状態のエネルギー=0 と設定):
$$\alpha = (E_T + E_S)/4, \quad \beta = (E_S - E_T)/4, \quad \gamma = (E_T - E_S)/4, \quad \delta = -(E_T + E_S)/4$$

Qiskitの Rz(θ) = exp(-iθZ/2) を使って $e^{-iH_0 dt/\hbar}$ を実装するには:
$$\theta_0 = 2\beta \cdot dt/\hbar, \quad \theta_1 = 2\gamma \cdot dt/\hbar, \quad \theta_{zz} = 2\delta \cdot dt/\hbar$$

**誤ったコード（修正前）:**
```python
theta_0 = -2 * beta * dt / hbar   # 符号が逆!
theta_1 = -2 * gamma * dt / hbar  # 符号が逆!
theta_zz = -2 * delta * dt / hbar # 符号が逆!
```

**正しいコード（修正後）:**
```python
theta_0 = 2 * beta * dt / hbar
theta_1 = 2 * gamma * dt / hbar
theta_zz = 2 * delta * dt / hbar
```

#### 3.1.3 誤りの影響

- 修正前のコードは $U_{H_0}^{\dagger}$（時間反転）を実装していた
- T1状態の相対位相: 正しくは +1.1719 rad、誤りでは -1.1719 rad
- S1状態の相対位相: 正しくは +2.3437 rad、誤りでは -2.3437 rad
- 位相差は $2 \times 2.3437 = 4.6875$ rad（S1状態）

#### 3.1.4 数値検証結果
```
max|U_fixed - phase*U_correct| = 1.24e-16  (完全一致)
max|U_current - phase*U_correct^dag| = 1.24e-16  (修正前は時間反転)
```

### 3.2 バグ2: Quditノイズシミュレータの不正なノイズ適用

#### 3.2.1 問題の所在
- `tutorials/mqt_qudits_noisy_simulator.py`

#### 3.2.2 誤りの詳細

**修正前の実装:**
1. 各Trotterステップで全体のユニタリ $U_{step}$ を一度に適用
2. ステップ後に**一度だけ**グローバル脱分極を適用
3. 脱分極は全81次元空間に対して適用（$\rho \to (1-p)\rho + p I_{81}/81$）
4. 密度行列の固有値分解で純粋状態をサンプル

**問題点:**
- ノイズは各2-quditゲートに対して個別に適用されるべき
- グローバル脱分極ではなく、2-qudit対の部分空間に対する脱分極であるべき
- 1ステップあたり6個の2-quditゲートがあるのに、p=0.01を1回だけ適用
- 実効的なノイズ量が正しい値の約1/6以下

**結果:** quditノイズシミュレーションがノイズなしの場合とほとんど同じ結果を示し、不自然に高い精度を見せていた。

#### 3.2.3 修正後の実装

**密度行列シミュレーション with per-gate noise:**
1. per-pair ユニタリ行列を構築（古典シミュレータと同じ方式）
2. 各2-quditゲート（H_transfer用CEx、H_TTA用CustomTwo）の後に個別の脱分極チャネルを適用
3. 正確な2-qudit脱分極チャネル: $\varepsilon(\rho) = (1-p)\rho + p \cdot \text{Tr}_{ij}(\rho) \otimes I_{ij}/d^2$
4. 部分トレース($\text{Tr}_{ij}$)はnumpy einsumで効率的に計算
5. 最終的な対角確率から測定ショットをサンプル

**ゲート数とノイズ蓄積の比較:**
| 項目 | Qubit | Qudit |
|------|-------|-------|
| 2体ゲート数/ステップ | 44 CX | 6 CEx/CustomTwo |
| 1ステップ実効ノイズ | 1-(1-0.01)^44 = 35.7% | 1-(1-0.01)^6 = 5.9% |
| ノイズ削減倍率 | - | 7.3× |

## 4. Qubit表現における非物理状態リークの分析

### 4.1 リークの原因
Qubit符号化では各分子に2 qubitを使用し、|11⟩が非物理状態となる。脱分極ノイズは計算基底の全状態にランダムに振幅を分散させるため、|11⟩状態への「リーク」が発生する。

### 4.2 リークの程度
H0のZZ項に対するCXゲート、およびH_transfer/H_TTAのUnitaryGateのtranspilation後の多数のCXゲートにそれぞれ1%の脱分極が適用される。1ステップあたり44個のCXゲートがあるため、ステップ毎の実効ノイズは約36%に達する。

### 4.3 H0符号誤りとの関連
H0の符号誤りは時間発展の位相を反転させ、H_transferおよびH_TTAとの干渉パターンを変化させる。これにより、正しい場合に比べて異なる（しかし必ずしも大きくはない）誤差が生じる。符号修正後はH0が正確に実装されるため、ノイズなしの場合は古典シミュレータとの誤差は数値精度（~10^-14）まで一致する。

### 4.4 バグ修正は根本的なリーク問題を解決するか
**H0符号修正**: ノイズなしの場合の精度を完全に修復するが、ノイズありの場合のリーク問題は解決しない（リークはCXゲートの脱分極ノイズに起因）。

**重要**: qubit表現でのノイズによるリークは、実際の量子コンピュータで起こる物理的に正しい現象である。非物理状態|11⟩への漏れは、qubit符号化の本質的な欠点であり、バグではない。Qudit符号化ではこの問題が存在しないため、同じ2体ゲートノイズ率でもquditの方が優位となる。

## 5. Qudit表現の精度に関する分析

### 5.1 ノイズなしの場合
Quditシミュレータは`build_trotter_step_unitary_direct()`でHamiltonianから直接ユニタリを計算する。これは`scipy.linalg.expm`を使用しており、古典シミュレータと数学的に完全に等価である（同じper-pairトロッター分解を使用）。したがって、ノイズなしの場合にquditの精度が非常に高いのは**正しい動作**である。

### 5.2 ノイズありの場合（修正前）
修正前はp=0.01のグローバル脱分極を1回だけ適用していたため、実効的なノイズが極めて小さく、ノイズなしとほぼ同じ結果になっていた。**これは不正確な実装によるものであり、問題があった。**

### 5.3 ノイズありの場合（修正後）
修正後は各2-quditゲート（1ステップあたり6個）に対して個別にp=0.01の2-qudit脱分極を適用する。実効的なステップ毎ノイズは約5.9%であり、20ステップで累積した場合は顕著な影響を与えるが、qubitの35.7%/ステップに比べて大幅に小さい。

**修正後のquditがqubitより優れた精度を示す理由:**
1. 必要な2体ゲート数が少ない（6 vs 44）
2. 非物理状態へのリークがない（3準位系に|11⟩のような余分な状態がない）

## 8. 結論

### 8.1 バグ1（H0符号誤り）の影響
- ノイズなしqubitシミュレーションの結果に位相誤りがあった
- 修正後、古典シミュレータとの誤差は数値精度（~10^-14）まで一致

### 8.2 バグ2（quditノイズ不正適用）の影響
- ノイズありquditシミュレーションのノイズ効果が不当に小さかった
- 修正後、正確な per-gate 2-qudit 脱分極が適用され、物理的に正しいノイズ蓄積を反映

### 8.3 qubit vs qudit の本質的な差異
qudit符号化がqubit符号化より優れた精度を示すのは以下の本質的な理由による:
1. **ゲート数の削減**: 2体ゲートが7.3倍少ない
2. **状態リークの不在**: 非物理状態が存在しない
3. **次元効率**: 3準位を直接表現できる

これらはqudit量子コンピューティングの本質的な利点であり、実装の問題ではない。
