## 原因分析

### Qubitが著しい精度低下を示す理由

**エンコーディング方式**:
- **分子あたり2量子ビット**を使用して3つの分子状態を表現
- 基底状態: |00⟩ (S0), |01⟩ (T1), |10⟩ (S1), **|11⟩ (禁制)**
- 3つの物理状態に対して4つの計算状態 → 1つの禁制状態

**ノイズのメカニズム**:
- 2量子ビットゲートへの標準的な脱分極ノイズは、4×4 = 16状態すべてに均等に影響
- 禁制状態|11⟩への遷移を引き起こす可能性がある
- いったん|11⟩に入ると、物理的な分子ダイナミクスから「失われる」
- 複数のトロッターステップで蓄積

**数学的モデル**:
```
脱分極チャネル: ρ → (1-p)ρ + p·I/16
```
ここでI/16は禁制状態|11⟩を等確率で含む。

### Quditがほとんど精度低下を示さない理由

**エンコーディング方式**:
- **分子あたり1つのqutrit（3準位系）**を使用
- 基底状態: |0⟩ (S0), |1⟩ (T1), |2⟩ (S1)
- 3つの物理状態に対して3つの計算状態 → **禁制状態なし**

**ノイズのメカニズム**:
- 2quditゲートへの脱分極ノイズは3×3 = 9状態に影響
- 9状態すべてが分子ペアの有効な物理状態に対応
- ノイズは個体数を再分配するが、物理的部分空間内に留まる
- 非物理的状態への個体数損失なし

**数学的モデル**:
```
脱分極チャネル: ρ → (1-p)ρ + p·I/9
```
ここでI/9内の9状態すべてが物理的に有効。

## 発見・修正された実装問題

### 問題: CExゲートの角度検証エラー

**ファイル**: `tutorials/exact_qudit_basic_gates.py`

**エラーメッセージ**:
```
AssertionError: Angle should be in the range [0, 2*pi]: 0
```

**根本原因**:
- CExゲートの検証は角度が[0, 2π]の範囲にあることを要求
- 計算された角度 `theta = V * dt / hbar = 15.19ラジアン` が2π (6.28)を超える
- H_transfer進化を適用しようとしたときに検証が失敗

**適用された修正** (49-51行目):
```python
# 回転角の計算
theta = V * dt / hbar
# CExゲート検証に必要な[0, 2π]範囲に角度を正規化
theta = theta % (2 * np.pi)
```

**追加修正** (一貫性のため186-190行目):
```python
theta = V * dt / hbar
# 注: 理論的検証では、cos/sinが周期的なため、角度の正規化は厳密には不要。
# ただし、CExゲート使用との一貫性のため、[0, 2π]範囲に正規化。
theta_normalized = theta % (2 * np.pi)
```

**影響**:
- ✓ 検証エラーなしでquditシミュレーションを実行可能に
- ✓ 数学的に等価（cosとsinは周期的）
- ✓ 物理やシミュレーション結果に変更なし

## 結論

### 検証ステータス: ✓ 合格

期待される動作の両方が確認されました:
1. ✓ ノイズありQubitは**著しく精度が悪化**（35%劣化、68%非物理的）
2. ✓ ノイズありQuditは**ほとんど精度低下なし**（0.5%劣化、0%非物理的）

### 実装ステータス: ✓ 正しい

両シミュレータのノイズモデル実装は物理的に正しく、設計通りに動作しています。観測された動作はエンコーディング方式の基本的な違いと一致します。

### 適用された修正: ✓ 最小限

最小限の修正のみが必要でした:
- CExゲート検証のための`exact_qudit_basic_gates.py`での角度正規化
- ノイズモデルやシミュレーションロジックへの変更なし
- ヒューリスティックまたはフォールバック回避策なし

### 物理的洞察

qubitとqudit実装間のノイズ耐性の劇的な違いは、エンコーディングの基本的な帰結です:

**Qubitエンコーディングのペナルティ**: 3準位系ごとに⌈log₂(3)⌉ = 2量子ビットを使用する必要があり、ノイズの多い進化の「シンク」として機能する禁制状態を作成します。

**Quditの利点**: 直接表現により禁制状態を排除し、ノイズ誘起エラーを物理的部分空間内に保ちます。

これは、非2のべき乗レベル構造を持つシステムをシミュレートするためのqudit量子コンピューティングの主要な利点を示しています。
