## 問題の再確認

### 当初の問題

**観測された現象**:
```
Qubit実装:  44ゲート/トロッターステップ
Qudit実装:  6,182ゲート/トロッターステップ
差:         約140倍
```

**根本原因**:
- CustomTwoゲート（9×9ユニタリ）の一般的分解アルゴリズム（LogEntQRCEXPass）が疎構造を無視
- 各CustomTwoゲートが約1,000個の基本ゲートに分解される
- 6個のCustomTwoゲート → 約6,000ゲート
