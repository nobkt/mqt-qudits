# MQT Qudits Tutorials

This directory contains tutorial documentation for the MQT Qudits framework.

## Contents

### doc/

Theoretical documentation on quantum dynamics:

- **quantum_dynamics_molecular_triplet_states.md**: Comprehensive theory of quantum dynamics for molecular systems with ground singlet state (S₀), excited triplet state (T₁), and excited singlet state (S₁). This document covers:
  - Triplet excitation energy transfer between adjacent molecules
  - Triplet-triplet annihilation (TTA) processes
  - Fluorescence emission from excited singlet states
  - Complete mathematical formulations with Hamiltonians, operators, and rate equations

## Language

The documentation is written in Japanese (日本語) with full LaTeX mathematical formulations.
