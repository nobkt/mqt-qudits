## 技術的分析

### 実際の分子ハミルトニアンの構造

#### H_transfer (エネルギー移動)

**物理的意味**:

- 隣接分子間のエネルギー移動プロセス
- |01⟩ ↔ |10⟩ の2準位遷移

**ハミルトニアン**:

```
H_transfer = V (|0⟩_i⟨1| ⊗ |1⟩_j⟨0| + h.c.)
           = V σ_x  (2×2部分空間)
```

**時間発展演算子**:

```
U = e^{-i V σ_x dt / ℏ} = [[cos(θ), -i sin(θ)],
                           [-i sin(θ), cos(θ)]]
θ = V dt / ℏ
```

**9×9行列での表現**:

- アクティブ基底: |01⟩ (index 1), |10⟩ (index 3)
- 非ゼロ要素: 4個 (2×2部分空間)
- 残り77要素: 単位行列

**分解結果**:

- ZYZ分解: θ = 2θ, φ = π/2, λ = π/2
- MQTゲート: 単一のR回転ゲート
- 最適化: すでに最小形式

#### H_TTA (三重項-三重項消滅)

**物理的意味**:

- 隣接分子間の三重項消滅プロセス
- |11⟩ ↔ |20⟩ ↔ |02⟩ の3準位遷移

**ハミルトニアン**:

```
H_TTA = J (|2⟩_i⟨1| ⊗ |0⟩_j⟨1| + |0⟩_i⟨1| ⊗ |2⟩_j⟨1| + h.c.)

3×3部分空間:
H_sub = J [[0, 1, 1],
           [1, 0, 0],
           [1, 0, 0]]
```

**時間発展演算子**:

```
固有値: λ_1 = -√2 J, λ_2 = 0, λ_3 = √2 J
U_sub = V diag(e^{-i λ_k dt / ℏ}) V†
```

**9×9行列での表現**:

- アクティブ基底: |02⟩ (index 2), |11⟩ (index 4), |20⟩ (index 6)
- 非ゼロ要素: 9個 (3×3部分空間)
- 残り72要素: 単位行列

**分解結果**:

- QR分解（Givens回転）: 3つの回転 + 対角位相
- MQTゲート: 約12ゲート → 最適化後6ゲート
- 最適化: VirtRz結合により50%削減
