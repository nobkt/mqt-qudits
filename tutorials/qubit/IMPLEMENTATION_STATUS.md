### 2. 実装アーキテクチャ

設計書に基づく6つの主要クラス：

```
QubitMolecularDynamicsSimulator (メインクラス)
├── PhysicalParameters (パラメータ管理)
├── StateEncoder (状態エンコーディング)
├── HamiltonianGates (ゲート実装)
│   ├── H0Gates (対角エネルギー項)
│   ├── TransferGates (エネルギー移動項)
│   └── TTAGates (三重項-三重項消滅項)
├── TrotterCircuitBuilder (回路構築)
├── ObservableCalculator (観測量計算)
└── Validator (検証とエラーチェック)
```

### 3. 実装の複雑性

#### Qudit版との比較

| 項目 | Qutrit (MQT-Qudits) | Qubit (本実装) | 比率 |
|------|-------------------|---------------|------|
| 1分子の表現 | 1 Qutrit（3次元） | 2 Qubit（4次元） | 2倍 |
| 4分子系のqubit/qutrit数 | 4 | 8 | 2倍 |
| 状態空間次元（物理的） | 81 | 81 | 同じ |
| 状態空間次元（全体） | 81 | 256 | 3.16倍 |
| 未使用状態 | 0 | 175 (68%) | - |
| ゲート数/ステップ | 約55個 | 約430個 | 約8倍 |

#### 主要な技術的課題

1. **状態エンコーディングの複雑性**
   - 3準位を2 qubitで表現 → 1準位が未使用（|11⟩）
   - 物理的部分空間を厳密に保存する必要
   - すべてのゲート操作で|11⟩への遷移を防止

2. **ゲート分解の複雑性**
   - H0: 5ゲート/分子（Quditの2.5倍）
   - H_transfer: 25ゲート/ペア（Quditの5倍）
   - H_TTA: 40ゲート/ペア（Quditの5倍）

3. **多重制御ゲートの実装**
   - Toffoliゲートの分解（15ゲート）
   - 多重制御RXXゲートの分解（25ゲート）
   - 条件付き回転の実装
