## 📚 QubitとQuditの比較

### なぜQubit版が重要か

| 側面               | Qutrit (MQT-Qudits)         | Qubit (本実装)                        |
| ------------------ | --------------------------- | ------------------------------------- |
| ハードウェア可用性 | 実験段階（限定的）          | 広く利用可能（IBMQ, Rigetti, IonQ等） |
| ゲート効率         | 高効率（55ゲート/ステップ） | 低効率（430ゲート/ステップ、約8倍）   |
| 実機での実行       | 限定的                      | 現実的に可能                          |
| 数学的厳密性       | 完全に保証                  | 完全に保証                            |

**結論**: Qubit版は効率が劣るが、**現在広く利用可能なハードウェアで実行可能**という大きな利点があります。
