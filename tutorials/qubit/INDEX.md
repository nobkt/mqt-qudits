## 📊 QubitとQuditの比較

### 定量的比較表

| 項目                    | Qutrit (MQT-Qudits) | Qubit (本実装)   | 比率      |
| ----------------------- | ------------------- | ---------------- | --------- |
| **状態表現**            |
| 1分子の表現             | 1 Qutrit（3次元）   | 2 Qubit（4次元） | 2倍       |
| 4分子系の次元           | $3^4 = 81$          | $2^8 = 256$      | 3.16倍    |
| 物理的部分空間          | 81                  | 81               | 同じ      |
| 未使用状態              | 0 (0%)              | 175 (68%)        | -         |
| **計算複雑性**          |
| Qudit/Qubit数           | 4                   | 8                | 2倍       |
| H0ゲート数              | 10個                | 40個             | 4倍       |
| Transferゲート数        | 30個                | 150個            | 5倍       |
| TTAゲート数             | 48個                | 240個            | 5倍       |
| **総ゲート数/ステップ** | **55個**            | **430個**        | **7.8倍** |
| 回路深さ/ステップ       | 約20                | 約120            | 6倍       |
| **リソース**            |
| メモリ使用量            | 約0.5MB             | 約2MB            | 4倍       |
| シミュレーション時間    | 1×                  | 5-10×            | -         |

### 定性的比較

| 側面               | Qutrit     | Qubit      | 推奨   |
| ------------------ | ---------- | ---------- | ------ |
| 実装の自然性       | ⭐⭐⭐⭐⭐ | ⭐⭐⭐     | Qutrit |
| ハードウェア可用性 | ⭐⭐       | ⭐⭐⭐⭐⭐ | Qubit  |
| ゲート効率         | ⭐⭐⭐⭐⭐ | ⭐⭐       | Qutrit |
| 実機での実行       | ⭐⭐       | ⭐⭐⭐⭐⭐ | Qubit  |
| 数学的厳密性       | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 同等   |
| 保守性             | ⭐⭐⭐     | ⭐⭐⭐⭐   | Qubit  |

### 結論

- **Qutrit版**: より自然で効率的だが、ハードウェアが限定的
- **Qubit版**: ゲート数は多いが、現在広く利用可能なハードウェアで実行可能

## ✅ 実装方針

### 使用するもの（許可）

✅ **必須**:

- Qiskitの標準量子ゲートのみ
- 数学的に厳密な鈴木トロッター分解
- ゲートの組み合わせによる正確な演算子実装
- 物理的部分空間の厳密な保存

### 使用しないもの（明示的に禁止）

❌ **厳禁**:

- `scipy.linalg.expm` による行列指数関数の直接計算
- 近似的なfallback処理
- ヒューリスティックな手法
- 非物理的な状態への遷移
- その他のごまかし

### 理由

本実装は、**数学的厳密性と物理的整合性を最優先**します。すべての演算は、Qiskitの標準ゲートを組み合わせることで、理論的に正当化される形で実装されます。
